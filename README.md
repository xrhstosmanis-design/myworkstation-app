
# MyWorkStation App — Shift Manager 0.1

Πρώτη λειτουργική έκδοση του προγράμματος βαρδιών.

## Τι περιλαμβάνει
- Dashboard
- 11 αρχικούς εργαζομένους και τους βασικούς περιορισμούς τους
- Μόνιμο και έκτακτο προσωπικό
- Προσθήκη / απενεργοποίηση εργαζομένου
- Βάρδιες:
  - Πρωί 06:00–14:00
  - Ενδιάμεση 11:00–19:00
  - Απόγευμα 14:00–22:00
  - Βράδυ 22:00–06:00
  - Delivery Δευτέρα–Παρασκευή 06:00–14:00
  - Υπεύθυνος Δευτέρα–Παρασκευή 07:00–15:00
- Αυτόματη δημιουργία εβδομαδιαίου προγράμματος
- Μέχρι 6 ημέρες ανά εργαζόμενο
- Προτεραιότητα στο μόνιμο προσωπικό και χρήση έκτακτων για κενά
- Προειδοποιήσεις για ακάλυπτες βάρδιες
- Responsive εμφάνιση για κινητό και υπολογιστή

## Εκτέλεση τοπικά
1. Εγκατάσταση Node.js 20+
2. Στον φάκελο του έργου:
   npm install
   npm start
3. Άνοιγμα: http://localhost:8080

## Ανέβασμα στο Render
- Δημιούργησε νέο Web Service από το GitHub repository.
- Build command: `npm install`
- Start command: `npm start`
- Το `render.yaml` περιλαμβάνεται ήδη.

## Σημείωση
Αυτή είναι η πρώτη έκδοση πρωτοτύπου. Τα δεδομένα αποθηκεύονται σε αρχεία JSON.
Στην επόμενη φάση θα μεταφερθούν σε PostgreSQL και θα προστεθούν login, επιχειρήσεις,
καταστήματα, άδειες, χειροκίνητες αλλαγές βαρδιών και εξαγωγή PDF/Excel.
