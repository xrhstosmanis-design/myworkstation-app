
# MyWorkStation App v0.3

Η πρώτη έκδοση με λειτουργική καρτέλα εργαζομένου και αυτόματη δημιουργία βαρδιών.

## Νέα στην v0.3
- Επεξεργασία εργαζομένου.
- Ενεργοποίηση/απενεργοποίηση εργαζομένου.
- Γραφικό περιβάλλον κανόνων ανά εργαζόμενο.
- Επιτρεπόμενες βάρδιες.
- Εβδομαδιαίος στόχος ανά βάρδια.
- Προτεραιότητα ανά βάρδια.
- Μέγιστες ημέρες και ώρες.
- Δυνατότητα 6ης ημέρας.
- Πρώτη λειτουργική Shift Engine.
- Προτεραιότητα μόνιμου προσωπικού.
- Χρήση έκτακτων όταν υπάρχουν κενά.
- Ακάλυπτες θέσεις και προειδοποιήσεις.
- Εβδομαδιαία προβολή προγράμματος.

## Εγκατάσταση
1. Αντέγραψε `.env.example` σε `.env`.
2. Ρύθμισε το `DATABASE_URL`.
3. Εκτέλεσε:
   - `npm install`
   - `npm run prisma:generate -w server`
   - `npm run prisma:dev -w server`
   - `npm run seed`
   - `npm run dev`
