# MyWorkStation App v0.4

Cloud-ready έκδοση για GitHub και Render.

## Εγκατάσταση
Δεν χρειάζεται να τρέξεις τοπικά `npm`, PostgreSQL ή Prisma.

1. Ανέβασε τα αρχεία στο GitHub.
2. Render → New → Blueprint.
3. Σύνδεσε το repository.
4. Apply.

Δες το `DEPLOY_RENDER.md`.

## Περιλαμβάνει
- Login
- PostgreSQL + Prisma
- Επιχειρήσεις και καταστήματα
- Μόνιμο και έκτακτο προσωπικό
- Κανόνες εργαζομένων
- Αυτόματη δημιουργία βαρδιών
- Αυτόματη βάση και seed στο Render
