[ ] RECOVER_KAT_DRY_RUN.cmd γράφει DRY_RUN_PASSED, checksum/revision και δεν αλλάζει τη συντόμευση.
[ ] RECOVER_KAT.cmd επαναφέρει το αποθηκευμένο HTTPS Store Mode URL μόνο μετά από εγκεκριμένο maintenance window.
[ ] Δημιουργείται MyWorkStation_KAT_Recovery.txt.
[ ] Επιβεβαίωση ότι Kiosk Manager, CapDriver, RBS και Windows services έμειναν αμετάβλητα.
