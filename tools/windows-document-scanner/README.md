# MyWorkStation document scanner connector — candidate / AWAITING HARDWARE

Windows 10/11, a vendor-supported WIA scanner driver and exactly one WIA scanner are required. TWAIN-only devices are not supported by this candidate. Confirm the intended scanner model/driver before purchase. The operator scans one page per button press and appends further pages to the same document where that existing form permits it (up to five). Scanning does not register a payment or send a chat message.

Technician build: `dotnet publish tools/windows-document-scanner/MyWorkStation.DocumentScanner.csproj -c Release -r win-x64 --self-contained true -o scanner-release`.

For explicit one-time setup, close any existing connector, extract the complete package and run `INSTALL.cmd` as the intended Windows user. The technician installs the connector under that user's LocalAppData and a minimized Startup shortcut for that user only. No administrator/network/firewall exception, public listener, filesystem scan output or remote-control agent is required. The listener binds only `127.0.0.1:17839`. Manual launch without installation is also supported. Respect Windows/organization script and application policies; no execution-policy or security bypass is included. Installation is never executed by a web request or the CI test.

In the current MyWorkStation document form, press **Σάρωση εγγράφου**, enter the six-digit code shown locally, and press **Σύνδεση σαρωτή**. The code expires after ten minutes or five failed attempts and is consumed once. The device pairing token is saved in the current browser profile's local storage; Windows stores its matching copy encrypted with DPAPI CurrentUser. Pairing survives a browser/connector/computer restart and does not scan. Browser-profile removal, another Windows account or explicit reset requires technician pairing again. Close the connector first, run `MyWorkStation.DocumentScanner.exe --reset-pairing`, restart it and pair the browser again to revoke the old token. Press **Σάρωση εγγράφου** explicitly to acquire a page. The browser may request local-network permission; do not bypass certificate/browser warnings or weaken browser security. Unavailable browser support is a compatibility failure, not a successful installation.

The connector requests color/300dpi when the driver supports these values. It retains the scanner's full acquisition area and returns JPEG bytes in memory; it does not clean/crop away rows or write a local image/PDF. Existing MyWorkStation controls perform document review and any separately selected paid/credit or send action. Original and processed-image retention depend on that existing consumer; this connector does not certify their archival policy.

Only the exact production Origin is accepted. JSON POST plus session bearer authority is required for scan; GET, other Origins, missing tokens, oversized bodies and bad page counts are rejected. There is one physical scan in flight, no automatic retry, and replay of the same request ID returns its recorded result rather than triggering another scan. Only the encrypted pairing token is written locally; document pixels are not. The latest result remains in process RAM until replaced or the connector closes; do not treat ordinary managed-memory cleanup as forensic zeroization. Cancel/close in the browser can discard an eventual result but cannot guarantee the physical feeder stops.

Verification: Windows workflow compiles and runs `--self-test` against actual loopback HTTP with a synthetic scanner. Hardware transfer/driver, browser permission and real document legibility remain **NOT TESTED** until measured on the intended PC/scanner. No universal scanner compatibility or production-installed claim follows from compilation.

This WIA-only candidate does not certify that model. Confirm an actual WIA transfer on the intended driver/device before purchase; TWAIN support remains a separate extension, not an installed capability.
