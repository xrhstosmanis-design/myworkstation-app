# Συμφωνία stock με όλες τις πηγές

- Η LAB δοκιμή στο `COCA COLA 1LT` έδειξε ψευδή διαφορά `-1`, επειδή η πώληση εμφανιζόταν στις κινήσεις αλλά δεν συμμετείχε στο άθροισμα συμφωνίας.
- Ο έλεγχος του module «Έλεγχος Απωλειών» αθροίζει πλέον τις χειροκίνητες κινήσεις, τις εγκεκριμένες αγορές, τις ολοκληρωμένες πωλήσεις/επιστροφές και τις αυτόματες αναλώσεις συνταγών.
- Η προστασία του επί πληρωμή module και η μόνιμη πρόσβαση Super Admin παραμένουν αμετάβλητες.
- Αναμενόμενο LAB αποτέλεσμα για `COCA COLA 1LT`: τρέχον `9`, καταγεγραμμένες κινήσεις `9`, διαφορά `0`, συμφωνία stock.
