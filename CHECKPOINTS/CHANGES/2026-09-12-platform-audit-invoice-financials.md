# Οικονομικά στοιχεία στο modal Συμβάντων Super Admin

## LAB εύρημα

Το κεντρικό modal `Platform Admin → Συμβάντα` εμφάνιζε μόνο ημερομηνία, συμβάν, περιγραφή, ποσό, κατάστημα και χειριστή. Η νέα αναλυτική μορφοποίηση είχε εφαρμοστεί μόνο στη διαφορετική προβολή Αναφορών.

## Διόρθωση

- Η invoice-specific μορφοποίηση γίνεται κοινός client helper.
- Το modal Super Admin αποκτά στήλη «Οικονομικά στοιχεία».
- Οι δύο προβολές εμφανίζουν πλέον τα ίδια nested δεδομένα τιμολογίου.
- Η αλλαγή είναι αποκλειστικά παρουσίασης και δεν γράφει οικονομικά ή αποθηκευτικά δεδομένα.
