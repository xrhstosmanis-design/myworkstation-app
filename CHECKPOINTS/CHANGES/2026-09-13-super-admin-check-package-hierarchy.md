# Checkpoint — κληρονομικότητα πακέτων ελέγχου Super Admin

**Ημερομηνία:** 13/09/2026

## Πρόβλημα

Στη δοκιμή του Κυλικείου ΚΑΤ εμφανίστηκε ενεργό μόνο το PREMIUM, ενώ το BASIC παρέμενε οπτικά κλειδωμένο. Ο backend επέτρεπε εκτέλεση μόνο όταν ήταν ενεργό το `BASIC_CHECK`, άρα ένα ανώτερο πακέτο δεν έδινε τα δικαιώματα που περιγράφει.

## Διόρθωση

- Ενεργό `PREMIUM_CHECK` δίνει BASIC και COMPLETE δικαιώματα.
- Ενεργό `COMPLETE_CHECK` δίνει BASIC δικαιώματα.
- Η εκτέλεση BASIC δέχεται οποιοδήποτε ενεργό πακέτο ελέγχου για το ίδιο εταιρικό κατάστημα.
- Οι κάρτες των κληρονομημένων πακέτων γράφουν «Περιλαμβάνεται στο …» και δεν επιτρέπουν άκυρη απενεργοποίηση του παράγωγου δικαιώματος.
