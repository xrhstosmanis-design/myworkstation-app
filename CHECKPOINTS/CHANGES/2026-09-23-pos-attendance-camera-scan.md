# POS — σάρωση κάρτας εργασίας με κάμερα

Ημερομηνία: 2026-09-23  
Κατάσταση: **PRODUCTION PASS / FALLBACK FIX LOCAL PASS**

## Αλλαγή

- Στην καρτέλα «Κάρτα» του παραθύρου Κάρτα εργασίας υπάρχει κουμπί «Σάρωση με κάμερα».
- Ζητείται άδεια κάμερας μόνο όταν πατηθεί το κουμπί.
- Η κάμερα αναγνωρίζει Code 128 και καταχωρίζει αυτόματα το αποτέλεσμα στην υπάρχουσα ασφαλή διαδρομή `attendance-card/scan`.
- Εμφανίζεται πλαίσιο στόχευσης ώστε να τοποθετείται ολόκληρο το barcode στην εικόνα.
- Το camera stream κλείνει μετά από επιτυχή ανάγνωση, αλλαγή σε PIN, κλείσιμο κάμερας ή κλείσιμο modal.
- Όταν το εγγενές `BarcodeDetector` λείπει (όπως στο Store Mode), χρησιμοποιείται ενσωματωμένος ZXing decoder για Code 128.
- Η προεπισκόπηση της κάμερας δημιουργείται συγχρονισμένα πριν ζητηθεί το stream, ώστε το Store Mode να μην ανοίγει και να κλείνει αμέσως την κάμερα.
- Ο ZXing fallback περιορίζεται σε Code 128 με `TRY_HARDER`, χρησιμοποιεί συχνότερη ανάλυση καρέ και ζητά εικόνα 1920×1080.
- Η εκτυπώσιμη κάρτα έχει πλέον ασφαλές λευκό περιθώριο 12 modules σε κάθε άκρη του Code 128 για αξιόπιστη αναγνώριση.
- Μετά από πραγματικό LAB όπου η συγκεκριμένη webcam δεν διάβασε αξιόπιστα ούτε το βελτιωμένο Code 128, η κάρτα εκτυπώνει επιπλέον QR του ίδιου ασφαλούς κωδικού.
- Η κάμερα δέχεται QR ή Code 128, ενώ το κανονικό scanner συνεχίζει να χρησιμοποιεί το Code 128.
- Πραγματικό LAB PASS: το νέο QR αναγνωρίστηκε από την webcam και καταχώρισε σωστά προσέλευση.
- Πραγματικό LAB FAIL: το φυσικό scanner υπέβαλε τον πολύ πυκνό γραμμωτό κωδικό ως διαφορετική τιμή και δεν βρήκε ενεργό εργαζόμενο.
- Η επόμενη έκδοση κάρτας χρησιμοποιεί μικρότερο deterministic token `MW2` (64-bit HMAC prefix), μεγαλύτερο quiet zone και αδιατάρακτη αναλογία modules για αξιόπιστη σάρωση. Η μετάβαση επιτρέπεται μόνο από τον ακριβή παλιό deterministic κωδικό.
- Πραγματικό LAB PASS με ENG: φυσικό scanner κατέγραψε προσέλευση και QR κατέγραψε αποχώρηση· η προστασία άμεσης διπλής σάρωσης λειτούργησε.
- Όταν το Windows keyboard ήταν στα Ελληνικά, το HID scanner έστειλε ελληνικούς χαρακτήρες. Η κανονικοποίηση μετατρέπει πλέον μόνο τα επιτρεπόμενα ελληνικά πλήκτρα της μορφής `MW2 + hex` στα αντίστοιχα λατινικά, τόσο στην παρουσία όσο και στην είσοδο POS.
- Πραγματικό LAB: η ήδη εκτυπωμένη legacy κάρτα `MWSWC…` απέτυχε με ελληνική διάταξη, επειδή τα πλήκτρα `W` και `S` μετατρέπονταν πρόωρα στο ίδιο κεφαλαίο `Σ`. Η κανονικοποίηση διατηρεί πλέον τη διάκριση `ς → W` και `σ → S` και καλύπτει ρητά τα prefixes `MW2` και `MWSWC`.
- Πραγματική έξοδος scanner με ΕΛ και κεφαλαία: `Μ΅282261Ψ1Β9Ε1ΑΦ573`. Το `Shift+W` της ελληνικής διάταξης παράγει `΅`, οπότε προστέθηκε η ακριβής αντιστοίχιση `΅ → W` και regression test με τον πραγματικό κωδικό.
- Σε άρνηση άδειας εμφανίζεται σαφές μήνυμα και παραμένουν διαθέσιμα PIN και εξωτερικό scanner.

## Δεν αλλάζει

- Η λογική προσέλευσης/αποχώρησης και το Workforce Audit.
- Η επιλογή προσωπικού PIN.
- Η εισαγωγή με εξωτερικό barcode scanner ή πληκτρολόγηση.
- Πωλήσεις, πληρωμές, stock, fiscal και ταμειακές λειτουργίες.

## LAB acceptance

1. POS → Κάρτα εργασίας → Κάρτα → Σάρωση με κάμερα.
2. Παροχή άδειας κάμερας στον Chrome/Edge.
3. Τοποθέτηση της εκτυπωμένης κάρτας μέσα στο πράσινο πλαίσιο.
4. Αυτόματη αναγνώριση και μήνυμα σωστής προσέλευσης.
5. Δεύτερη σάρωση και μήνυμα σωστής αποχώρησης.
6. Έλεγχος Παρουσιών και Audit για μέθοδο `POS_CARD`.
