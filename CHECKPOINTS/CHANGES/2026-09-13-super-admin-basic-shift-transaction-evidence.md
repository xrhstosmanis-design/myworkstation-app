# Super Admin BASIC — αποδεικτικά κινήσεων βάρδιας

Κάθε BASIC εύρημα διαφοράς εμφανίζει πλέον τις έως 50 νεότερες κινήσεις της ίδιας κλεισμένης βάρδιας. Κάθε στοιχείο έχει ώρα, ποσό, τύπο, χειριστή, περιγραφή, αναγνωριστικό και ένδειξη αντιστροφής.

Η ανάγνωση είναι μόνο για τη συγκεκριμένη εταιρεία, κατάστημα και βάρδια. Δεν μεταβάλλει οικονομικά δεδομένα.

Επαλήθευση πριν το push: server syntax check PASS, στοχευμένα tests Super Admin 7/7 PASS, production client build PASS.

Εκκρεμεί CI, Render deploy και οπτική δοκιμή χρήστη στο LAB.
