# Επισκευή εκτέλεσης PREMIUM — έγκυρη SQL σειρά

- Το PostgreSQL DISTINCT ON (s.id) απαιτεί η SQL ταξινόμηση να αρχίζει από το s.id.
- Επαναφέρθηκε η έγκυρη SQL ταξινόμηση. Η χρονολογική ταξινόμηση για συσχέτιση γίνεται ήδη μέσα στον PREMIUM αλγόριθμο, άρα ο κανόνας 40″ και επόμενη/μεθεπόμενη δεν αλλάζει.
