# LAB terminal shift dashboard — 2026-09-08

## Scope

- Αποκλειστικά `MYWORKSTATION LAB` / `ΕΡΓΑΣΤΗΡΙΟ ΔΟΚΙΜΩΝ`.
- Δεν δημιουργείται συναλλαγή, παραλαβή, επιστροφή ή εξωτερική εντολή fiscal/EFTPOS.

## Τι αλλάζει

1. Η αρχική σελίδα καταστήματος εμφανίζει πρώτα τις ενεργές βάρδιες.
2. Κάθε ενεργό terminal εμφανίζεται ως ξεχωριστή επιλέξιμη βάρδια.
3. Με επιλογή terminal εμφανίζονται μόνο οι δικές του κινήσεις, τρόποι πληρωμής και σύνολα.
4. Η επιλεγμένη βάρδια περιλαμβάνει ανάλυση πωλήσεων ανά κατηγορία προϊόντος.
5. Οι υπάρχουσες ενέργειες πληρωμών/αρχείων δεν αφαιρούνται: μεταφέρονται μετά τον έλεγχο ταμείου.

## Πύλη

PR → πράσινο CI → merge → Render → οπτικός έλεγχος στο LAB.
