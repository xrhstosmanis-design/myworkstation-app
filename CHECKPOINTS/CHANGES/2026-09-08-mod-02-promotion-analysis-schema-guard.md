# MOD-02 — προστασία schema ανάλυσης

Η read-only ανάλυση προσφορών εξασφαλίζει πρώτα τα πρόσθετα πεδία `SaleLine` πριν εκτελέσει το query. Αυτό επιτρέπει ασφαλή μετάβαση σε ήδη υπάρχουσες βάσεις χωρίς ορατό σφάλμα.

- Δεν αλλάζει πωλήσεις, τιμές, απόθεμα ή ρυθμίσεις συσκευών.
- Η αλλαγή είναι additive (`ADD COLUMN IF NOT EXISTS` / index).
