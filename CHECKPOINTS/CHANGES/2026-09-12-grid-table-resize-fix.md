# Διόρθωση αλλαγής πλάτους σε grid πίνακες

## LAB εύρημα

Στο `Αναφορές → Συμβάντα / Audit` η κάθετη λαβή εμφανιζόταν, αλλά δεν άλλαζε το πλάτος της στήλης.

## Αιτία

Τα CSS grid πλάτη επιστρέφονται ως τιμές όπως `204px`. Η χρήση `Number("204px")` επέστρεφε `NaN`, οπότε δημιουργούνταν άκυρα `NaNpx` και το σύρσιμο δεν είχε αποτέλεσμα.

## Διόρθωση

- Τα grid tokens μετατρέπονται με `Number.parseFloat`.
- Ελέγχεται ότι όλα τα πλάτη είναι πεπερασμένοι αριθμοί.
- Σε μη αναμενόμενο CSS format χρησιμοποιούνται τα πραγματικά πλάτη των κεφαλίδων.
- Η ίδια διόρθωση καλύπτει όλους τους υποστηριζόμενους grid πίνακες BackOffice/Platform.
