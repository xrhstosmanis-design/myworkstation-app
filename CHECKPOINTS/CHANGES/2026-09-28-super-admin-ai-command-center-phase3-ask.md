# Super Admin AI Command Center — ΦΑΣΗ 3 «Ρώτα το MyWorkStation»

**Ημερομηνία:** 28/09/2026
**Κατάσταση:** `LOCAL IMPLEMENTATION · AWAITING CI / DEPLOY / USER PASS`

## Στενή αλλαγή

- Προστέθηκε read-only περιοχή ερώτησης μέσα στο υπάρχον AI Command Center.
- Η απάντηση βασίζεται μόνο στο ήδη φορτωμένο snapshot εταιρειών, καταστημάτων και μετρητών των υπαρχόντων ελέγχων Ταμείων, Πληρωμών και Τράπεζας.
- Η απάντηση εμφανίζει σύντομη καθοδήγηση, έως πέντε σημεία, τις πηγές που χρησιμοποίησε και τον περιορισμό των διαθέσιμων στοιχείων.
- Υπάρχουν τρεις έτοιμες ερωτήσεις για γρήγορη δοκιμή.

## Όρια ασφαλείας

- Το endpoint `POST /api/platform/ai-command-center/ask` βρίσκεται πίσω από τον υπάρχοντα έλεγχο Platform Super Admin.
- Το request επικυρώνεται με αυστηρό, περιορισμένο schema.
- Δεν υπάρχουν AI tools, function calls, database writes ή δυνατότητα εκτέλεσης ενέργειας.
- Το μοντέλο καθοδηγείται να μην εφευρίσκει δεδομένα και να παραπέμπει στις κανονικές οθόνες όταν το snapshot δεν αρκεί.
- Δεν δημιουργείται δεύτερη βάση ή αποθηκευμένο αντίγραφο επιχειρηματικών δεδομένων.
- CI PASS δεν ισοδυναμεί με USER/LAB PASS.
