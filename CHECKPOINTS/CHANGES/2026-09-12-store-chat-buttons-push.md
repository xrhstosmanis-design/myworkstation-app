# Checkpoint — Store Chat buttons and push

- Διορθώθηκε το κουμπί Ανανέωση ώστε να λειτουργεί και κατά τον περιοδικό έλεγχο.
- Ο περιοδικός έλεγχος δεν μπλοκάρεται από παλιά κατάσταση busy.
- Παραμένει ανοικτή η υλοποίηση πλήρους Web Push subscription/VAPID για κλειστό browser.
- Εκκρεμεί LAB δοκιμή σε κινητό και PC.

- Διορθώθηκε το `Promise.all` των read receipts σε `Promise.allSettled`, ώστε αποτυχία καταγραφής ανάγνωσης να μην ακυρώνει την ανανέωση/φόρτωση του Chat.
- Παραμένει ξεχωριστή εργασία η πλήρης Web Push/VAPID ρύθμιση στο Render.
