# Checkpoint — Store Chat buttons and push

- Διορθώθηκε το κουμπί Ανανέωση ώστε να λειτουργεί και κατά τον περιοδικό έλεγχο.
- Ο περιοδικός έλεγχος δεν μπλοκάρεται από παλιά κατάσταση busy.
- Παραμένει ανοικτή η υλοποίηση πλήρους Web Push subscription/VAPID για κλειστό browser.
- Εκκρεμεί LAB δοκιμή σε κινητό και PC.

- Διορθώθηκε το `Promise.all` των read receipts σε `Promise.allSettled`, ώστε αποτυχία καταγραφής ανάγνωσης να μην ακυρώνει την ανανέωση/φόρτωση του Chat.
- Παραμένει ξεχωριστή εργασία η πλήρης Web Push/VAPID ρύθμιση στο Render.

- Διορθώθηκε η επαναφόρτωση μετά την καταγραφή read receipt, ώστε να εμφανίζονται άμεσα οι αναγνώστες.

- Η ανανέωση προστατεύεται από ταυτόχρονες κλήσεις, χρησιμοποιεί cache-busting και εμφανίζει σαφή κατάσταση φόρτωσης σε κινητό και PC.
- Εκκρεμούν CI, deploy και LAB retest.

- Η ένδειξη «Διαβάστηκε από» χρησιμοποιεί αξιόπιστο όνομα λογαριασμού (όνομα, email ή id ως τελευταίο fallback).
- Εκκρεμούν CI, deploy και LAB retest με δεύτερο λογαριασμό.

- Η οθόνη χειρίζεται πλέον readers ως array ή JSON string, ώστε να μην κρύβεται η ένδειξη ανάγνωσης.

- Η ένδειξη ανάγνωσης επιστρέφει και εμφανίζει άμεσα την ταυτότητα του τρέχοντος χρήστη μετά την καταγραφή read receipt.
- Εκκρεμούν CI, deploy και LAB retest.

- Τα αδιάβαστα μηνύματα εμφανίζονται πρώτα για τον τρέχοντα χρήστη.
