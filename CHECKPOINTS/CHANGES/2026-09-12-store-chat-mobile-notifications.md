# Checkpoint — Store Chat mobile notifications

- Προστέθηκε κουμπί ενεργοποίησης ειδοποιήσεων στο Chat.
- Το PWA service worker υποστηρίζει push payload και άνοιγμα της εφαρμογής.
- Η ειδοποίηση λειτουργεί όταν το Chat είναι ανοιχτό/σε background tab.
- Εκκρεμεί VAPID/Web Push ρύθμιση στο Render για πλήρες push όταν η σελίδα είναι κλειστή.
- Εκκρεμεί LAB δοκιμή σε Android κινητό και PC.
