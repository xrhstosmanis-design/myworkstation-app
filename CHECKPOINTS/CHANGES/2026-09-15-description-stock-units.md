# Description-driven stock units

Date: 2026-09-15
Reference invoice: AA0011467

Coffee and chocolate descriptions containing KG/KGR are converted to the product stock base in grams. Explicit TEM/TMX counts are converted to pieces. Invoice financial quantities and totals remain unchanged. Ambiguous descriptions are not guessed and remain reviewable before FINAL.
\n## Genuine repeated charges\n\nAn identical item printed twice is retained when the source contains both code occurrences and the missing row gross exactly closes the current invoice total. This prevents a legitimate second 12 OZ cup charge from being mistaken for OCR replay.\n
