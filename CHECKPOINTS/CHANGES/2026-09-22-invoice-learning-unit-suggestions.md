# Invoice Learning — popup προτάσεων μονάδας

## Αλλαγή

- Τα πεδία «Μονάδα τιμολογίου» και «Μονάδα stock» στη διόρθωση γραμμής έχουν αναπτυσσόμενες προτάσεις.
- Διαθέσιμες επιλογές: ΤΜΧ, ΚΟΥ, ΚΟΥΤΑ, ΚΙΒ, ΚΒ, ΣΥΣΚ, ΣΥΣΚΕΥΑΣΙΑ, ΠΑΚ, ΠΑΚΕΤΟ, ΚΙΛΟ, KG, ΓΡ, ΛΙΤΡΟ και L.
- Τα πεδία παραμένουν επεξεργάσιμα ώστε να μπορεί να γραφτεί μονάδα που δεν υπάρχει στη λίστα.

## Ασφάλεια

Η αλλαγή είναι μόνο στο UI. Δεν αλλάζει ποσότητες, μετατροπές, τιμές, εκπτώσεις, stock, πληρωμές ή λογιστική.

## Κατάσταση

Αναμονή για πράσινο CI, merge, Render deploy και οπτική δοκιμή.
