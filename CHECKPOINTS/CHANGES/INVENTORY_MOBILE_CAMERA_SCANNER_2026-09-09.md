# Inventory 2.0 — mobile camera scanner — 2026-09-09

- Προστέθηκε σαφές κουμπί «Σάρωση με κάμερα» στη mobile απογραφή.
- Ανοίγει την πίσω κάμερα και αναγνωρίζει EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, ITF, Codabar και QR.
- Με την αναγνώριση κλείνει την κάμερα, επιλέγει το προϊόν και μεταφέρει τον χρήστη στην ποσότητα.
- Η ροή συνεχίζει να χρησιμοποιεί το υπάρχον tenant/stocktake grant και δεν αλλάζει δικαιώματα ή δεδομένα αποθήκης πριν από την καταχώρηση.
- Αν ο browser δεν υποστηρίζει BarcodeDetector, εμφανίζεται σαφής οδηγία για Chrome και παραμένει διαθέσιμη η χειροκίνητη εισαγωγή.
