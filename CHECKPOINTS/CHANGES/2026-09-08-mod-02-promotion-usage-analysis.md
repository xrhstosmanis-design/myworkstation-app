# MOD-02 — Ανάλυση χρήσης προσφορών

## Αλλαγή

- Κάθε νέα γραμμή POS που εφαρμόζει προσφορά καταγράφει το `promotionId` και τον τύπο της προσφοράς.
- Η κεντρική οθόνη Προσφορών Super Admin εμφανίζει αναγνωστικά τα ποσά πωλήσεων, εκπτώσεων και επιστροφών για τις προσφορές που έχουν πλέον πραγματική σύνδεση με γραμμές πώλησης.

## Όρια ασφαλείας

- Καμία τιμή, προσφορά, απόθεμα, βάρδια, POS mapping ή συσκευή δεν αλλάζει από την ανάλυση.
- Οι παλαιές πωλήσεις δεν αποδίδονται τεχνητά σε προσφορά. Η μέτρηση αρχίζει από νέες πωλήσεις μετά το deploy.
- Η επιλογή και τα ποσά προμηθευτών παραμένουν ξεχωριστό επόμενο βήμα `MOD-03`.

## Επαλήθευση πριν από PR

- `git diff --check`: PASS.
- `node --check` στα routes POS και προσφορών: PASS.
- Η παραγωγική client build δεν εκτελέστηκε τοπικά επειδή το περιβάλλον δεν επέτρεψε λήψη εξαρτήσεων. Θα ελεγχθεί από το GitHub CI.
