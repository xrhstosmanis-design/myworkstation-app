# Νο 21 — Μία μετατροπή συσκευασίας στο απόθεμα

[Ανάθεση και αποτέλεσμα LAB](2026-11-16-no21-lab-mixed-unit-result.md), PR #3951. Η καταχώριση έγραφε τεμάχια αποθήκης στη βασική κίνηση και στη συνέχεια πρόσθετε ξανά τη διαφορά μετατροπής.

Η βασική κίνηση αγοράς ακολουθεί πλέον την ποσότητα παραστατικού που ελέγχει η επαναφορά. Η υπάρχουσα καταγεγραμμένη διόρθωση προσθέτει τη διαφορά προς τα τεμάχια αποθήκης μία φορά. Οι γραμμές παραστατικού, το καθαρό κόστος σύγκρισης και οι εξαιρέσεις αποθέματος διατηρούνται. Δεν εφαρμόζεται μαζική αναδρομική διόρθωση.

Η δοκιμή επαναφοράς περιλαμβάνει τώρα ρητή μονάδα PACKAGE μετά από επαναφορά αγοράς, έλεγχο συνολικής ποσότητας, επαναληπτική τιμολόγηση και αντιστροφή των κινήσεων. Εκκρεμεί CI με απομονωμένη PostgreSQL. Αποδοχή στο υπάρχον ΕΡΓΑΣΤΗΡΙΟ ΔΟΚΙΜΩΝ: καταγραφή αρχικού υπολοίπου, μία δοκιμαστική συσκευασία έξι τεμαχίων, καθαρή αύξηση +6, καμία νέα κίνηση κατά την επανάληψη, σωστή τιμή σύγκρισης και επαναφορά δοκιμαστικού υπολοίπου. Καμία πληρωμή, φορολογική έκδοση ή αποστολή.
