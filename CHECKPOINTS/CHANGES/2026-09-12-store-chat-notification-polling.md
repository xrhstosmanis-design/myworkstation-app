# Checkpoint — Store Chat notification polling

- Διορθώθηκε η απουσία αυτόματου ελέγχου νέων μηνυμάτων.
- Το Chat ελέγχει νέα μηνύματα ανά 15 δευτερόλεπτα.
- Η ειδοποίηση εμφανίζεται όταν το Chat βρίσκεται στο παρασκήνιο και έχει δοθεί άδεια.
- Εκκρεμεί πλήρες Web Push με VAPID για ειδοποίηση με κλειστό browser.
- Εκκρεμεί LAB δοκιμή σε Android.
