# Διαγραφή πρόχειρου τιμολογίου: audit και καθαρισμός αρχείου

## Πρόβλημα

Η διαγραφή της πρόχειρης αγοράς αφαιρούσε μόνο την `PurchaseOrder` και τις γραμμές της. Το συνδεδεμένο πρόχειρο παραστατικό, η εργασία AI και η φωτογραφία στη Θυρίδα παρέμεναν, δεν εμφανιζόταν συμβάν διαγραφής και η νέα ανάγνωση του ίδιου αρχείου μπλοκαριζόταν ως duplicate.

## Διόρθωση

- Δημιουργείται `PURCHASE_ORDER_DELETED` στο `StoreOperatorAudit` μέσα στην ίδια συναλλαγή.
- Το συμβάν εμφανίζεται στην κεντρική αναφορά «Συμβάντα / Audit».
- Για συνδεδεμένο πρόχειρο διαγράφονται `PurchaseDocumentLine`, `PurchaseDocument`, `DocumentInbox`, `AiReaderJob` και το συγκεκριμένο `DocumentAttachment`.
- Το duplicate check δεν θεωρεί πλέον την απλή παρουσία εγγραφής Θυρίδας από μόνη της ολοκληρωμένη καταχώριση.
- Ενεργή πληρωμή εμποδίζει τη διαγραφή μέχρι να ακυρωθεί με την προβλεπόμενη οικονομική ροή.

## Έλεγχοι

- Syntax checks στις τρεις server routes.
- 23 στοχευμένα regression tests επιτυχώς.
- `git diff --check` επιτυχώς.
