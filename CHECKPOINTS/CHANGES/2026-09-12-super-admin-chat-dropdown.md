# Checkpoint — Ενιαίο Chat με pop-down στον Super Admin

- Το Chat εμφανίζεται ως ένα κεντρικό κουμπί στην επάνω ομάδα `Έλεγχοι` του Super Admin.
- Αφαιρέθηκε η προηγούμενη παρουσίαση με χωριστά αιωρούμενα κουμπιά ανά κατάστημα.
- Με πάτημα ανοίγει παράθυρο επιλογής με ένα pop-down.
- Κάθε επιλογή εμφανίζεται ως `Πελάτης · Κατάστημα`, ώστε να είναι σαφές σε ποιο tenant ανήκει.
- Με την επιλογή ανοίγει το κοινό `StoreChatPanel` για το συγκεκριμένο κατάστημα.
- Τα server-side δικαιώματα, το tenant/store scoping και το audit παραμένουν αμετάβλητα.
- Στοχευμένο test, 1110/1110 server tests και client production build: PASS.
- Εκκρεμούν CI, deploy και LAB retest.
