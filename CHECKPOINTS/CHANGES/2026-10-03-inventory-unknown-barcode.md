# 03/10/2026 — Inventory 2.0 mobile/tablet unknown barcode

Status: IMPLEMENTED / AWAITING CI

Unknown scans now present two clear actions: attach barcode to an existing active product in the same company/store, or continue to new-product creation. Barcode ownership conflicts are blocked. Attaching also adds the product to the active stocktake. New-product continuation preserves stocktake/barcode return context. UI uses large touch-friendly controls.
