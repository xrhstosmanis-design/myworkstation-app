# Audit κύκλου πρόχειρου τιμολογίου

## Στόχος

Να καλυφθούν τα βήματα του χειροκίνητου πρόχειρου τιμολογίου που δεν άφηναν δικό τους λειτουργικό ίχνος.

## Υλοποίηση

- Καταγράφονται δημιουργία και ενημέρωση πρόχειρου.
- Καταγράφονται προσθήκη και διαγραφή γραμμής μαζί με τα οικονομικά στοιχεία της.
- Κάθε audit εγγραφή είναι στην ίδια database transaction με την αλλαγή.
- Όλα τα συμβάντα είναι company/store-scoped και δηλώνουν `stockChanged: false`.
- Προστέθηκαν ελληνικές ονομασίες στο κεντρικό Audit.

## Επαλήθευση

- 9/9 στοχευμένες δοκιμές invoice flow, server syntax checks και client production build: PASS.
- Μετά το deploy απαιτείται LAB χειροκίνητο πρόχειρο με προσθήκη, αλλαγή και διαγραφή γραμμής.
