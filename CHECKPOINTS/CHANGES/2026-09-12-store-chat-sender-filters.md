# Checkpoint — Αποστολέας και φίλτρα Chat

- Κάθε μήνυμα εμφανίζει `Από: [όνομα]`.
- Το όνομα ανακτάται tenant/store-scoped τόσο από χρήστη BackOffice όσο και από Store Operator.
- Η αναζήτηση καλύπτει κείμενο, όνομα αρχείου, κατηγορία και αποστολέα.
- Υπάρχει φίλτρο ημερομηνίας και φίλτρο αποστολέα.
- Η λίστα αποστολέων δημιουργείται μόνο από τη συγκεκριμένη συνομιλία καταστήματος.
- Υπάρχει ένα κουμπί καθαρισμού όλων των ενεργών φίλτρων.
- Η περιοχή φίλτρων προσαρμόζεται σε desktop, tablet και κινητό.
- Στοχευμένο test, 1114/1114 server tests και client production build: PASS.
- Εκκρεμούν CI, deploy και LAB retest.
