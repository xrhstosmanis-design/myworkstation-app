# Invoice Learning Lab — professional financial view

- The current Learning draft now opens directly as a professional supplier invoice without first saving it to history.
- The view includes original price, three discounts, net unit price, net line value, VAT, gross line value and review state.
- A financial control compares the printed invoice total with the independently calculated line total using the existing €0.05 tolerance.
- Confirmed corrections continue to be saved centrally for the same supplier and are available across stores.
- Viewing and learning do not create payment, accounting, stock, approval or finalization movements.
