# Invoice Learning — ρητός τύπος παραστατικού

## Πρόβλημα

Κανονικό «ΤΙΜΟΛΟΓΙΟ ΠΩΛΗΣΗΣ – ΔΕΛΤΙΟ ΑΠΟΣΤΟΛΗΣ» χαρακτηρίστηκε λανθασμένα ως πιστωτικό. Η παλιά ανίχνευση έψαχνε γενικά τις ρίζες `ΠΙΣΤ` και `ΕΠΙΣΤΡΟΦ` σε όλο το αναγνωρισμένο κείμενο, οπότε μπορούσε να ενεργοποιηθεί από άσχετη αναφορά ή προηγούμενο αρνητικό υπόλοιπο.

## Αλλαγή

- `CREDIT_NOTE` μόνο με ρητό τίτλο «Πιστωτικό Τιμολόγιο», «Πιστ. Τιμ.», «Credit Note» ή «Δελτίο Επιστροφής».
- Το «ΤΙΜΟΛΟΓΙΟ ΠΩΛΗΣΗΣ» παραμένει `INVOICE` με προηγούμενο υπόλοιπο `-0,02` ή μεμονωμένη λέξη «επιστροφή».
- Η ίδια οδηγία εφαρμόζεται και στο OpenAI fallback.
- Προστέθηκε regression test με το πραγματικό σενάριο.

## Όρια

Δεν αλλάζουν η ανάγνωση γραμμών, ποσότητες, τιμές, εκπτώσεις, συσκευασίες, προεπεξεργασία φωτογραφίας, POS, πληρωμές ή stock.

## Κατάσταση

Αναμονή για πράσινο CI, merge, Render deploy και νέα εισαγωγή του τιμολογίου.
