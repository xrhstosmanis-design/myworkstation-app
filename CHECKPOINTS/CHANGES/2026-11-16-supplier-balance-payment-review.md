# Υπόλοιπα προμηθευτών

PR #3921. Ενιαίος κανόνας πληρωμών στις αναφορές και εμφάνιση πληρωμών Ανοιχτών Τιμολογίων στη θυρίδα. Πέρασαν 16 τοπικές δοκιμές. Εκκρεμεί CI και LAB.

Η ίδια παρτίδα ελέγχει αναδρομική σύνδεση υπάρχουσας φωτογραφίας POS, απόρριψη διφορούμενης αντιστοίχισης και επανάληψη χωρίς δεύτερη σύνδεση. Η νέα δοκιμή με PostgreSQL εκκρεμεί στο CI.
