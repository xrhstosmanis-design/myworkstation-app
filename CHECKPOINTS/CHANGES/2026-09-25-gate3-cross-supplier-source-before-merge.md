## Περιορισμένη νέα αλλαγή

- Σε γενικό μονοσέλιδο όπου το πρώτο σύνολο γραμμών διαφέρει από το επιβεβαιωμένο ποσό POS, δοκιμάζεται πρώτα ανεξάρτητη ανάγνωση της πρωτότυπης εικόνας με κενό οδηγό. Μόνο αν επαληθευτούν **όλες** οι σειρές, αλυσίδες ποσότητας/τιμής/εκπτώσεων, τυπωμένες ομάδες ΦΠΑ και ποσό, ο πλήρης πίνακας αντικαθιστά τον προσωρινό. Δεν προστίθεται τότε δεύτερος πίνακας ή Azure και δεν μεταβάλλονται οι επαληθευμένοι συντελεστές ΦΠΑ. Σε αποτυχία συνεχίζει η υπάρχουσα συμπληρωματική διαδρομή και η αποτυχία παραμένει ορατή, χωρίς νέα προσπάθεια του ίδιου ανεξάρτητου verifier με την ίδια εικόνα.
- Το κουμπί «Διόρθωση προσχεδίου με AI» αφαιρείται από το BackOffice και καταργείται το αντίστοιχο POST endpoint. Δεν χρησιμοποιείται για Gate 3. Δεν διαγράφονται ή αλλάζουν τα ήδη αποθηκευμένα πρόχειρα.
- Τα παραδείγματα ΜΟΥΧΛΑΚΗΣ 14/490/1.791,63 € ΦΠΑ 0%, ΣΤΕΦΑΝΙΔΗΣ 16/356/1.359,66 € και ΚΟΝΤΟΓΙΑΝΝΗΣ 2/26,56 € ΦΠΑ 13% δοκιμάζουν τον οικονομικό ελεγκτή με σωστές και εσκεμμένα λανθασμένες σειρές. Αυτά **δεν** είναι δοκιμή του OCR παρόχου πάνω σε όλες τις πρωτότυπες εικόνες. Τοπικά: 1.457 server PASS / 1 SKIP / 0 FAIL, frontend build PASS, diff check PASS. PR #1194, GitHub CI PASS και merge `f93ed98b2d137896b3cdc813c751f5536314b092`. Το δημόσιο Render `/api/health` επέστρεψε ακριβώς αυτό το revision στις 25/09. Νέα γνήσια POS ανάγνωση LAB εκκρεμεί.
