# Invoice Learning — supervised partial correction

- Το `REQUEST_FAILED` του Azure δεν οδηγεί πλέον σε απώλεια του μερικού αποτελέσματος μέσα στο Invoice Learning Lab.
- Το μερικό αποτέλεσμα εμφανίζεται ως επεξεργάσιμο πρόχειρο με σαφή προειδοποίηση.
- Προστέθηκε δυνατότητα προσθήκης κενής γραμμής για όσα είδη λείπουν από την ανάγνωση.
- Η επιβεβαίωση/εκμάθηση παραμένει χειροκίνητη από τον Super Admin.
- POS και παραγγελίες εξακολουθούν να απορρίπτουν μη συμφωνημένες/μερικές γραμμές.
- Έλεγχοι: στοχευμένα invoice-learning tests `16/16` PASS και JavaScript syntax checks PASS.
- Επόμενο: πράσινο CI, merge/deploy και νέα δοκιμή με το ίδιο τιμολόγιο ΔΕΛΤΑ.
