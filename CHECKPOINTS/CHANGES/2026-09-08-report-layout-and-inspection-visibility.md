# Διόρθωση ορατότητας αναφορών και ελέγχου Super Admin

- Οι τρεις πραγματικές εγγραφές «Διαγραφές λίστας πώλησης» φορτώθηκαν στο LAB. Προστίθεται συγκεκριμένη διάταξη εννέα στηλών ώστε τα στοιχεία να μην κρύβονται οριζόντια.
- Ο read-only έλεγχος Super Admin ήταν ενεργός αλλά βρισκόταν πίσω από το modal των τερματικών. Η ενέργεια προβάλλεται πλέον πάνω από το modal.
- Η λειτουργία παραμένει μόνο ανάγνωσης: δεν εκδίδει PIN, δεν ανοίγει βάρδια, δεν εκτελεί πώληση και δεν αλλάζει χειριστή.
