# Checkpoint — Καρφιτσωμένες ανακοινώσεις Chat

- Το API επιστρέφει ρητό δικαίωμα `canPin` από server-side έλεγχο ρόλου.
- Μόνο Ιδιοκτήτης ή Super Admin μπορεί να καρφιτσώσει ή να ξεκαρφιτσώσει ανακοίνωση.
- Χειριστής καταστήματος δεν λαμβάνει κουμπί διαχείρισης και το API απορρίπτει απευθείας απόπειρα.
- Μόνο μήνυμα κατηγορίας `ANNOUNCEMENT` μπορεί να καρφιτσωθεί.
- Η ενημέρωση παραμένει απομονωμένη ανά εταιρεία και κατάστημα.
- Τα audit events `STORE_CHAT_ANNOUNCEMENT_PINNED` και `STORE_CHAT_ANNOUNCEMENT_UNPINNED` κρατούν τον actor και το message/store context.
- Η οθόνη εμφανίζει ένδειξη `ΚΑΡΦΙΤΣΩΜΕΝΗ` και κουμπί καρφιτσώματος μόνο στον εξουσιοδοτημένο ρόλο.
- Διατηρείται η προτεραιότητα των αδιάβαστων· οι καρφιτσωμένες ανακοινώσεις προηγούνται μέσα στην ίδια ομάδα ανάγνωσης.
- Στοχευμένο test, 1109/1109 server tests και client production build: PASS.
- Εκκρεμούν CI, deploy και LAB retest.
