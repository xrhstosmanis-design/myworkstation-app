# Super Admin PREMIUM — πλήρης συσχέτιση ανά βάρδια

Η αλλαγή επεκτείνει τον PREMIUM έλεγχο ώστε να συσχετίζει στοιχεία μόνο μέσα στο ίδιο κλεισμένο `CashShiftSession`.

- Πιθανές διπλές POS πωλήσεις: ίδιο καλάθι, ποσό, χειριστής και χρονική εγγύτητα έως 10 λεπτά.
- Πιθανή αλλαγή μετρητά ↔ κάρτα χωρίς αντίστροφη εγγραφή: ίδιο καλάθι/ποσό αλλά διαφορετικές πληρωμές.
- Πιθανές επαναλαμβανόμενες ακυρώσεις/επιστροφές και καταγεγραμμένα POS safety events.
- Λειτουργικά συμβάντα DELETE/REMOVE/VOID/CANCEL εμφανίζονται μόνο όταν υπάρχει το αντίστοιχο audit table.
- COMPLETE έλεγχοι παραστατικών και διπλών πληρωμών περιορίζονται στην κλεισμένη βάρδια.

Κανόνες ασφάλειας:

- Καμία σύγκριση μεταξύ διαφορετικών βαρδιών.
- Μόνο ανάγνωση: καμία διόρθωση ταμείου, POS–EFTPOS, αποθήκης ή πληρωμής.
- Κάθε αποτέλεσμα είναι ένδειξη προς επιβεβαίωση, όχι αυτόματη αιτία ή απόδοση ευθύνης.

Τοπική επαλήθευση: 6/6 στοχευμένα tests, production build και `git diff --check` PASS.
