# Νο 16 · Android Chat (21/11/2026)

Η εφαρμογή Android εμφανίζει τη διαχείριση ομάδων και πρόσβασης μόνο όταν το API επιτρέπει διαχείριση για το επιλεγμένο κατάστημα, χρησιμοποιώντας τα δικαιώματα του #4109. Η αφαίρεση από μία ομάδα και η ανάκληση ή επαναφορά για όλο το Chat έχουν ξεχωριστές ενέργειες και ονομαστική επιβεβαίωση. Με την επόμενη ανανέωση, η εφαρμογή απομακρύνει από την οθόνη την ομάδα ή το Chat που έπαψε να είναι διαθέσιμο.

Προστέθηκε δοκιμή Android για τη διαθεσιμότητα με βάση την απάντηση του API και την επιβεβαιωμένη αφαίρεση. Εκκρεμούν τα αποτελέσματα CI, το υπογεγραμμένο APK και η συγκεντρωτική αποδοχή web/Android στο LAB.
