# Checkpoint — Chat ανά κατάστημα — foundation

## Κατάσταση

Η εργασία 19 ξεκίνησε σε branch από το τελευταίο `main`.

Προστέθηκαν:

- νέο module `STORE_CHAT` με store/company isolation και entitlement gate,
- server-side πίνακας μηνυμάτων ανά κατάστημα,
- API ανάγνωσης και αποστολής μηνυμάτων,
- κατηγορίες μηνυμάτων,
- audit αποστολής μηνύματος,
- βασική προστασία ώστε εργαζόμενος να βλέπει μόνο το δικό του κατάστημα.

## Δεν θεωρείται ολοκληρωμένο

Δεν έχουν ακόμη προστεθεί UI, φωτογραφίες/PDF, αναζήτηση, καρφίτσωμα, σύνδεση με τιμολόγια/βάρδιες/εκκρεμότητες ή LAB PASS. Η δοκιμή χρήστη θα ζητηθεί μόνο μετά από πράσινο CI και PR προς `main`.
