# Super Admin PREMIUM — αυστηρή χρονική και σειριακή συσχέτιση

- Πιθανή διπλή POS συναλλαγή ή αλλαγή μετρητά/κάρτα εξετάζεται μόνο αν οι συναλλαγές είναι της ίδιας κλεισμένης βάρδιας και του ίδιου χειριστή.
- Η χρονική απόσταση περιορίζεται αυστηρά στα 40 δευτερόλεπτα.
- Η δεύτερη κίνηση πρέπει να είναι η αμέσως επόμενη ή η μεθεπόμενη στη χρονολογική σειρά της βάρδιας.
- Οι κάρτες εξηγούν πλέον και τη διαφορά δευτερολέπτων και αν πρόκειται για επόμενη ή μεθεπόμενη συναλλαγή.
- Δεν αλλάζει κανένα οικονομικό δεδομένο ή λογιστικό αποτέλεσμα.
