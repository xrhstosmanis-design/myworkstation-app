# Checkpoint — Mobile responsive foundation

- Η υπάρχουσα εφαρμογή προσαρμόστηκε για μικρές οθόνες χωρίς νέα ξεχωριστή σελίδα.
- Καλύπτονται login, navigation, cards, panels, tables με οριζόντια κύλιση, modals και βασικές φόρμες.
- Δεν αλλάζουν backend, δεδομένα, ρόλοι ή POS fiscal ροές.
- Εκκρεμεί πραγματικός έλεγχος LAB σε Android και iPhone.
