# Checkpoint — Αδιάβαστα μηνύματα Chat πρώτα

- Το API υπολογίζει `readByMe` για τον συνδεδεμένο λογαριασμό, με tenant/store scoping.
- Τα αδιάβαστα επιστρέφονται πρώτα και μέσα σε κάθε ομάδα εμφανίζονται τα νεότερα πρώτα.
- Η απλή φόρτωση του Chat δεν χαρακτηρίζει πλέον όλα τα μηνύματα ως διαβασμένα.
- Η ανάγνωση καταγράφεται μόνο όταν ο χρήστης πατήσει το αδιάβαστο μήνυμα.
- Ο αποστολέας δεν βλέπει το δικό του μήνυμα ως αδιάβαστο.
- Προστέθηκαν ένδειξη `ΝΕΟ`, μετρητής αδιάβαστων και ασφαλής χρήση με πληκτρολόγιο/αφή.
- Στοχευμένο test, 1109/1109 server tests και client production build: PASS.
- Εκκρεμούν CI, deploy και LAB retest με δύο λογαριασμούς.
