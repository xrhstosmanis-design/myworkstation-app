# Κεντρική αναζήτηση ΑΦΜ ΑΑΔΕ — 29/09/2026

Η εικόνα `image(20260929-191003).png` έδειξε το γενικό μήνυμα «Το ΑΦΜ δεν βρέθηκε στο βασικό μητρώο ΑΑΔΕ» σε υπάρχουσα καρτέλα προμηθευτή. Το κοινό route επέστρεφε το ίδιο 404 όταν η υπηρεσία απαντούσε HTTP σφάλμα ή όταν δεν υπήρχε αναγνώσιμη επωνυμία. Επιπλέον, για ήδη καταχωρισμένο ΑΦΜ επέστρεφε τοπική καρτέλα χωρίς εξωτερική ερώτηση. Άρα το μήνυμα δεν αποδεικνύει αποτέλεσμα μητρώου.

Η κεντρική διόρθωση προσθέτει ρητή παράμετρο `official=1` στην οθόνη επεξεργασίας, παρακάμπτει μόνο την τοπική συντόμευση, επιστρέφει τεχνικό 502 για HTTP ή μη αναγνώσιμη απάντηση, και σαφές 409 όταν δεν υπάρχει ενεργή σύνδεση AADE στο εταιρικό κατάστημα. Η κοινή διαδρομή ισχύει για όλες τις εταιρείες και καταστήματα με απομόνωση `companyId`/`storeId`. Δεν αγγίζει διαπιστευτήρια, προμηθευτές, παραστατικά, stock ή οικονομικά δεδομένα. Η επιτυχής ενέργεια στην υπάρχουσα UI συνεχίζει να αποθηκεύει την καρτέλα· αυτό πρέπει να είναι σαφές στον χρήστη κατά το τελικό LAB.

Η παλαιότερη κεντρική δοκιμή 10/09 καταγράφει αναζήτηση και επιλογή προμηθευτή, αλλά δεν περιέχει live απόκριση ΑΑΔΕ για αυτή την εταιρεία. CI, deploy και live LAB εκκρεμούν. Τοπικό `node --test` μπλοκαρίστηκε από μη εγκατεστημένες εξαρτήσεις (`express`).
