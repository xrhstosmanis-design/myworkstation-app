# POS FAST — πιστωτικό επιστροφής: αποτροπή λανθασμένης αγοράς

Τελευταίο πραγματικό LAB: **FAIL** για ΔΕΛΤΑ/ΦΙΛΩΝ 9946. Το πιστωτικό επιστροφής 6,04 € έγινε θετική νέα παραγγελία 4,67 €, δεύτερη ποσότητα 2,46 αντί 1. Το PASS ΣΙΓΜΑ ΑΤΤΙΚΗΣ 746,54 € αφορούσε κανονικό τιμολόγιο χωρίς εκπτώσεις· παλαιότερα ΟΧΟΝΟΣ/ΟΛΥΜΠΟΣ απέτυχαν. Gate 3 OPEN.

Αυτή η αλλαγή κλείνει **μόνο** τον επικίνδυνο αυτόματο δρόμο πιστωτικού προς αγορά. Το FAST header επισημαίνει CREDIT_NOTE από «ΠΙΣΤΩΤΙΚΟ»/CREDIT NOTE, η POS φόρμα απαιτεί ρητό τύπο και μπλοκάρει πιστωτικό πριν από duplicate check ή πληρωμή. Το server fast handoff απορρίπτει τόσο δηλωμένο πιστωτικό όσο και FAST σελίδα που το αναγνώρισε, καθώς και παλιό client χωρίς επιβεβαιωμένο τύπο, πριν από νέο job/πρόχειρο. Η υπάρχουσα ειδική ροή πιστωτικού BackOffice παραμένει ο δρόμος χειρισμού. Δεν επιχειρείται αβέβαιη αυτόματη μετατροπή ήδη υπάρχοντος πρόχειρου και δεν λύνεται η μετατόπιση ποσότητας OCR του 9946.

Προστατευόμενες συμπεριφορές: κανονικά τιμολόγια POS με ένα payment/job/draft, ανανέωση χωρίς δεύτερη πληρωμή, πλήρης οικονομικός έλεγχος, μηδενικές κινήσεις stock/fiscal από διαγνωστική δοκιμή. Τοπικά: regression cancel/confirm PAID/CREDIT, ειδικό credit note χωρίς financial writes, build PASS και server suite 1448 PASS / 1 SKIP / 0 FAIL. **AWAITING CI / MERGE / EXACT DEPLOY / GENUINE LAB**. Αποδοχή: νέο πραγματικό πιστωτικό δεν δημιουργεί αγορά ή πληρωμή στο POS και οδηγεί σε ροή πιστωτικού BackOffice· νέο διαφορετικό κανονικό τιμολόγιο συνεχίζει να δημιουργεί ένα πρόχειρο με ορθές γραμμές. Η οικονομική ανάγνωση πιστωτικού χρειάζεται χωριστό έργο και πραγματική δοκιμή.
