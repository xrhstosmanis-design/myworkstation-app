# 2026-09-23 - Κεντρική λίστα εκκρεμοτήτων και υποχρεωτική αφαίρεση μετά το PASS

## Σκοπός

Ενοποίηση όλων των πραγματικών εκκρεμοτήτων του MyWorkStation σε μία κεντρική πηγή, ώστε οι παράλληλες σελίδες να μη ξαναφτιάχνουν ολοκληρωμένες λειτουργίες.

Άμεση επιχειρησιακή προτεραιότητα: ετοιμότητα και εγκατάσταση καταστήματος έως Κυριακή 27/09/2026 πριν από την ανάπτυξη μεγάλου νέου module.

Η εγκατάσταση χαρακτηρίζεται ελεγχόμενη πιλοτική όσο παραμένουν ανοικτά Gates. Η επίσημη σειρά Gate 1-8 δεν αντικαθίσταται από τη μεταγενέστερη αναλυτική λίστα ιδεών.

## Νεότερος κανόνας ιδιοκτήτη

- Gate 1 και Gate 2 είναι PASS.
- Gate 3 έχει ανατεθεί σε άλλη σελίδα.
- Gate 5 είναι PASS.
- Κάθε άλλο ελεύθερο Gate μπορεί να αναληφθεί από διαφορετική σελίδα για παράλληλη πρόοδο.
- Η ανάθεση καταγράφεται πριν από την εργασία και κλειδώνει το scope για τη συγκεκριμένη σελίδα.
- Κάθε υποεργασία που παίρνει πραγματικό PASS διαγράφεται υποχρεωτικά από την pending λίστα από τη σελίδα που την ολοκλήρωσε.

## Παραδοτέα

- `docs/roadmap/PENDING_WORK.md`: ενεργή λίστα εκκρεμοτήτων και δεσμευτική σειρά συνέχειας.
- `output/pdf/MyWorkStation_Central_Pending_Roadmap_2026-09-23.pdf`: αναγνώσιμη έκδοση PDF.
- Ενίσχυση `AGENTS.md`, manual README και PR template με υποχρεωτική αφαίρεση κάθε πραγματικού PASS από την pending λίστα.

## Κανόνας

Το ίδιο PR που κλείνει πραγματικό PASS ενημερώνει checkpoint, active list, manual, pending roadmap και PDF. CI/local/merge/deploy χωρίς πραγματική δοκιμή παραμένει `AWAITING LAB`.

## Όρια

- Δεν αλλάζει κώδικας εφαρμογής, δεδομένα, schema, POS, fiscal ή οικονομική συμπεριφορά.
- Τιμολόγια/OCR και efood/Pelican παραμένουν στις εξειδικευμένες σελίδες τους.
- Τα ήδη επιβεβαιωμένα Workforce, Video Audit, Master Catalog και λοιπά PASS δεν επαναφέρονται ως εκκρεμότητες.
