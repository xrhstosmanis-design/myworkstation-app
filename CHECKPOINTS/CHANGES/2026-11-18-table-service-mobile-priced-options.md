# Νο 15 — Χρεώσιμες επιλογές παραγγελιοληψίας κινητού

Συνέχεια της ανάθεσης TABLE_SERVICE στον /root, με υποβοηθό /root/mobile. Κλάδος `feat/table-service-mobile-priced-options-20261118`. Η ενιαία δοκιμή LAB παραμένει υπό τον κεντρικό συντονισμό.

Η οθόνη κινητού επέτρεπε μόνο δωρεάν επιλογές, ενώ ο κοινός server πλέον επαληθεύει τις ενεργές επιλογές ανά προϊόν και κατάστημα, υπολογίζει την επίσημη τιμή και απορρίπτει αλλαγμένη τιμή με 409. Η αλλαγή ενεργοποιεί τις πραγματικές χρεώσιμες επιλογές στο κινητό. Η γραμμή, η ποσότητα, το σύνολο και η επιβεβαίωση περιλαμβάνουν την επιβάρυνση. Στέλνεται η τιμή του προστατευμένου καταλόγου και ο server διατηρεί τον τελικό έλεγχο.

Διατηρούνται τα υποχρεωτικά ελάχιστα/μέγιστα επιλογών, η προσωπική συνεδρία καταστήματος, η αποστολή με σύνδεση και το ίδιο αναγνωριστικό σε επανάληψη αβέβαιης απάντησης. Προϊόντα με περιβαλλοντική εισφορά ή SET συνεχίζουν από το POS.

Προστέθηκαν πραγματικές δοκιμές mounted React για χρεώσιμη επιλογή και ποσότητα, σύνολο και payload, περιορισμό υποχρεωτικής/μοναδικής επιλογής, ίδιο UUID μετά από αβέβαιη αποστολή, ορατή απόρριψη 409 με διατήρηση γραμμής, και μπλοκάρισμα εισφοράς/SET. Τοπικά Node20.20.2: 5/5 mounted React PASS, χωρίς παράλειψη. Production build PASS (Vite 36,11 s, έλεγχος TABLE_SERVICE bundle PASS). Πλήρες CI εκκρεμεί. Φυσικό κινητό, λειτουργική δοκιμή LAB και τελική αποδοχή παραμένουν NOT TESTED για τη νέα χρεώσιμη κινητή επιλογή.
