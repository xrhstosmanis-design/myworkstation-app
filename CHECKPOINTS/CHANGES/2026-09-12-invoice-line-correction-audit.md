# Audit διόρθωσης γραμμής τιμολογίου

## Στόχος

Κάθε χειροκίνητη διόρθωση αντιστοιχισμένης γραμμής να αφήνει πλήρες, tenant/store-scoped ίχνος μαζί με την εκμάθηση προμηθευτή.

## Υλοποίηση

- Το `INVOICE_LINE_CORRECTED` γράφεται στην ίδια database transaction με τη γραμμή και το supplier mapping.
- Αποθηκεύονται order/line/invoice/supplier, πλήρης κατάσταση πριν και μετά, καθώς και αν δημιουργήθηκε ή ενημερώθηκε κανόνας εκμάθησης.
- Η εγγραφή δηλώνει `stockChanged: false`: η αποθήκη εξακολουθεί να αλλάζει μόνο στην idempotent οριστικοποίηση.
- Το συμβάν προστέθηκε στο κεντρικό Audit με ελληνική ονομασία.

## Επαλήθευση

- 8/8 στοχευμένες δοκιμές purchase-order invoice flow: PASS.
- Server syntax checks και client production build: PASS.
