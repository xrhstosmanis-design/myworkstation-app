# Νο2 — verified ordinary posting projection

18/11/2026 Europe/Athens. Πρόσθετη πριν-source ανάληψη της ρητής απαίτησης ιδιοκτήτη για πραγματικές μη καταχωρισμένες αγορές και διαχωρισμό ήδη πληρωμένων. ASSIGNED `/root` Νο2, branch `feat/no2-monthly-counter-drilldown`, συνέχεια του #4032. Η ανεξάρτητη read-only διασταύρωση απέδειξε source/projection pairs με πραγματικό approved posting και stock receipt αλλά διαφορετική ημερομηνία τιμολογίου/καταχώρισης. Δεν πρόκειται για νέες αγορές που πρέπει να επαναληφθούν. Ιδιωτικά στοιχεία παραμένουν μόνο στην ιδιωτική αναφορά.

Μόνο ordinary derived view, πριν την επιλογή μήνα: επιτρέπεται να χρησιμοποιεί την ημερομηνία/αξία του αρχικού παραστατικού για τη ρητά αποδεδειγμένη posting projection, με provenance των raw τιμών. Απαιτούνται μοναδικά source/order/target, source backlink, ενεργή πηγή, INVOICED order, APPROVED PURCHASE_ORDER target, πλήρης σειρά/αριθμός/τύπος/supplier/ΑΦΜ, έγκυρες ημερομηνίες/ποσά και υπάρχουσα ανοχή0,05, πραγματικό μοναδικό PurchaseOrderPosting και ακριβές InvoiceStockPosting. Διπλές/αντικρουόμενες αξιώσεις αποκλείονται. Δεν συνδέονται ανεξάρτητα πρωτότυπα με ημερομηνία/όνομα/ποσό.

Τα raw facts μένουν στο fingerprint, ο C classifier implementation και το persisted D1 παραμένουν ακριβώς όπως πριν, και τα λοιπά C/email/writers/stock scopes διατηρούν τους υπάρχοντες owners. Αλλάζει μόνο η αποδεδειγμένη source/projection αναπαράσταση της ordinary αναφοράς και η αντίστοιχη οικονομική παρατήρηση. Δεν γίνεται παραγωγική μεταβολή τιμών, ημερομηνιών, πληρωμών, έγκρισης ή αποθέματος.
