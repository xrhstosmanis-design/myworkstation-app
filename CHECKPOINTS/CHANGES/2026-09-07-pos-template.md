# Checkpoint — Πρότυπο POS

- Προστέθηκε Super Admin επιλογή «Πρότυπο POS».
- Αντιγράφεται μόνο η δημοσιευμένη διάταξη POS σε επιλεγμένα καταστήματα.
- Δεν μεταφέρονται προϊόντα, χρήστες/PIN, ταμεία, τερματικά, αποθήκη, βάρδιες, συναλλαγές ή fiscal/EFTPOS δεδομένα.
- Πρώτη δοκιμή: MYWORKSTATION LAB, LAB-POS-01 στο Surface και LAB-POS-02 στο PC.
- PR: #556.
