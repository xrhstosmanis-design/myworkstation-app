# Κοινή αλλαγή πλάτους πινάκων BackOffice / Platform

## LAB εύρημα

Η ειδική native λύση του πίνακα Συμβάντων εμφάνιζε γκρι εσωτερικές μπάρες στις κεφαλίδες και η γραμμή αλλαγής πλάτους δεν λειτουργούσε αξιόπιστα.

## Διόρθωση

- Αφαιρείται το native CSS resize του συγκεκριμένου πίνακα.
- Ενισχύεται ο υπάρχων κοινός μηχανισμός για όλα τα κανονικά tables και τα υποστηριζόμενα grid tables του BackOffice/Platform.
- Τα πραγματικά πλάτη εφαρμόζονται σε fixed table layout και αποθηκεύονται ανά διαδρομή/πίνακα.
- Η λαβή γίνεται μόνιμα ορατή κάθετη γραμμή και μεγαλώνει κατά το hover/drag.
- Υποστηρίζονται pointer capture, ποντίκι και αφή.
- Τα δεδομένα παραμένουν read-only όπου ήταν read-only. Δεν προστίθεται επεξεργασία εγγραφών.
- Οι γρήγορες οθόνες POS και Store εξαιρούνται από την καθολική διακόσμηση.
