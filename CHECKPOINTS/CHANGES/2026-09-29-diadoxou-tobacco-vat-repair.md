# Διαδόχου · τμήμα καπνικών 0%

## Πηγή και εύρημα

- Η φωτογραφία του παλιού Kiosk Manager δείχνει `1.ΚΑΠΝΙΚΑ`: κωδικός 12, τμήμα ταμειακής 1, ΦΠΑ 0%.
- Read-only παραγωγής: 565 προϊόντα κατηγορίας ΚΑΠΝΙΚΑ συνδέονται στο τμήμα και έχουν ήδη `Product.vatRate=0`. Άλλα 20 προϊόντα διαφορετικών κατηγοριών με `vatRate=24` συνδέονται στο ίδιο τμήμα. Το `ManagementVatDepartment.vatRate` είναι 24, χωρίς κωδικό και αριθμό ταμειακής.
- Η απλή αλλαγή από τη φόρμα θα αντικαθιστούσε τον συντελεστή και των 20 ειδών. Δεν έγινε τέτοια αλλαγή.

## Διόρθωση PR #1538

- Κατά την εκκίνηση, μετά τη δημιουργία schema, στοχευμένο transaction μόνο για την εταιρεία του Διαδόχου ελέγχει ακριβώς 565 μηδενικά καπνικά και 20 άλλα είδη 24%.
- Μεταφέρει τα 20 είδη στο υπάρχον τμήμα `ΕΙΔΗ 24` χωρίς αλλαγή `Product.vatRate` και μετά ορίζει στο `1.ΚΑΠΝΙΚΑ` ΦΠΑ 0, κωδικό 12 και τμήμα ταμειακής 1.
- Αν τα δεδομένα διαφέρουν, ακυρώνει το transaction χωρίς μερική αλλαγή. Σε επόμενη εκκίνηση αναγνωρίζει την ολοκληρωμένη κατάσταση.
- Έγινε έλεγχος σύνταξης Node και σύγκριση SHA του GitHub tree με το τοπικό commit. Εκκρεμεί CI, merge, deploy και read-only επαλήθευση παραγωγής.

## Όρια

- Δεν ορίστηκαν κωδικοί εξαίρεσης ΦΠΑ. Τα υπόλοιπα τμήματα και η φυσική δοκιμή RBS/EFTPOS παραμένουν OPEN.
