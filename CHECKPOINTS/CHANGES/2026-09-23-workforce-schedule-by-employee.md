# Workforce V2 — πρόγραμμα ανά εργαζόμενο — 2026-09-23

## Κατάσταση

**PRODUCTION + COMPLETE USER LAB PASS**

## Νεότερο πραγματικό LAB

- Το δημοσιευμένο πρόγραμμα εμφανίζεται σωστά ανά ημέρα.
- Το μήνυμα στο Store Chat εμφανίζει όλες τις βάρδιες σε μία χρονολογική λίστα.
- Νέα απαίτηση: ξεχωριστή προβολή ανά εργαζόμενο με ημερομηνία, ώρες και εμφανές ΡΕΠΟ.
- Η υπάρχουσα προβολή ανά ημέρα παραμένει **PRODUCTION PASS / USER VISUAL PASS** και δεν ξαναφτιάχνεται.
- Πραγματικό οπτικό LAB PASS στο δημοσιευμένο πρόγραμμα έκδοσης 8: η προβολή «Ανά εργαζόμενο» εμφανίζει σωστά ξεχωριστές κάρτες, 3 ημέρες εργασίας / 4 ρεπό, ημερομηνίες, ονομασία βάρδιας, ώρες και εμφανές `ΡΕΠΟ`.
- Πραγματικό Store Chat LAB PASS: το νέο μήνυμα εμφανίζει ξεχωριστή ενότητα ανά εργαζόμενο, όλες τις ημερομηνίες της περιόδου, σωστή βάρδια/ώρες και καθαρό `ΡΕΠΟ` στις ημέρες χωρίς ανάθεση.

## Αλλαγή

- Προστίθεται τέταρτη προβολή «Ανά εργαζόμενο» δίπλα στις υπάρχουσες προβολές.
- Κάθε κάρτα εργαζομένου δείχνει όλες τις ημερομηνίες της περιόδου.
- Ημέρα με βάρδια δείχνει όνομα βάρδιας και ώρες.
- Ημέρα χωρίς ανάθεση δείχνει καθαρά «ΡΕΠΟ».
- Η κεφαλίδα δείχνει σύνολο ημερών εργασίας και ρεπό.
- Κάθε νέα δημοσίευση στέλνεται στο Store Chat ομαδοποιημένη ανά εργαζόμενο, με ημερομηνία, βάρδια/ώρες ή ΡΕΠΟ.
- Περιλαμβάνονται όλοι οι ενεργοί εργαζόμενοι του συγκεκριμένου καταστήματος και τυχόν εργαζόμενος που υπάρχει ήδη στην έκδοση.

## Όρια ασφαλείας

- Καμία αλλαγή σε ανάθεση, κανόνες, εγκρίσεις, δημοσίευση ή attendance.
- Καμία αλλαγή σε POS, πληρωμές, stock ή fiscal.
- Δεν επανεκδίδεται ούτε μεταβάλλεται παλιό δημοσιευμένο πρόγραμμα ή παλιό μήνυμα Chat.
- Η αλλαγή αφορά μόνο προβολή και μορφοποίηση μελλοντικού μηνύματος δημοσίευσης.

## Έλεγχοι

- Regression για UI «Ανά εργαζόμενο», ΡΕΠΟ και responsive κάρτες.
- Regression για store-scoped roster και νέο Chat format.
- Απαιτείται πλήρες πράσινο CI, merge και exact production revision πριν από LAB.

## LAB αποδοχή

1. Άνοιγμα ήδη δημοσιευμένου προγράμματος.
2. Επιλογή «Ανά εργαζόμενο».
3. Κάθε εργαζόμενος εμφανίζει όλες τις ημερομηνίες της εβδομάδας.
4. Οι ημέρες εργασίας έχουν σωστή βάρδια και ώρες.
5. Οι ημέρες χωρίς βάρδια γράφουν «ΡΕΠΟ».
6. Σε επόμενη πραγματική δημοσίευση, το Store Chat εμφανίζει την ίδια ομαδοποίηση ανά εργαζόμενο.

Και τα έξι κριτήρια ολοκληρώθηκαν με πραγματικό LAB PASS.
