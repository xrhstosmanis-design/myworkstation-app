# Super Admin COMPLETE — αποδεικτικά κινήσεων

Η οθόνη COMPLETE δεν εμφανίζει πλέον μόνο γενικό εύρημα ή λίστα IDs. Για κάθε πληρωμή/έξοδο χωρίς παραστατικό και για κάθε ομάδα πιθανής διπλής πληρωμής εμφανίζει τις πραγματικές κινήσεις με ώρα, ποσό, τύπο, χειριστή, περιγραφή, αναγνωριστικό και κατάσταση παραστατικού.

## Scope ασφαλείας

- Μόνο επιλεγμένη εταιρεία και κατάστημα.
- Μόνο ενεργές κινήσεις κλεισμένης βάρδιας.
- Μόνο ανάγνωση — καμία μεταβολή χρημάτων, παραστατικών ή εγγραφών.
