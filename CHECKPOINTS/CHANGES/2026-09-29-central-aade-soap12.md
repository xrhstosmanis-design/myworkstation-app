# Κεντρική ΑΑΔΕ — SOAP 1.2 — 29/09/2026

Η νέα εικόνα `image(20260929-195410).png` δείχνει HTTP 415 στην επίσημη αναζήτηση προμηθευτή. Το προηγούμενο κοινό route έστελνε SOAP 1.1 (`text/xml` και envelope 1.1), ενώ το ζωντανό WSDL της επίσημης υπηρεσίας δηλώνει `soap12:binding` και action `http://rgwspublic2/RgWsPublic2Service:rgWsPublic2AfmMethod`.

Το κοινό route στέλνει πλέον SOAP 1.2 (`application/soap+xml`, envelope 1.2, ακριβές action WSDL). Χωρίς διαπιστευτήρια ή ΑΦΜ έγινε μη μεταβλητική δοκιμή της επίσημης μεθόδου `rgWsPublic2VersionInfo` με τον ίδιο τύπο περιεχομένου και envelope: HTTP 200 και SOAP 1.2 απόκριση. Αυτό τεκμηριώνει επίλυση ασυμβατότητας μέσου, όχι επιτυχία πιστοποιημένης αναζήτησης ΑΦΜ. Κανένα στοιχείο προμηθευτή δεν τροποποιήθηκε από τη διάγνωση.

CI, Render και πραγματική δοκιμή χρήστη στο `rgWsPublic2AfmMethod` εκκρεμούν. Η διόρθωση είναι κεντρική για όλες τις εταιρείες και τα καταστήματα.
