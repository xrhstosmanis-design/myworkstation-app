- **IMPLEMENTED**: the named bounded delegated read exists in source. It does not certify hosted/manual acceptance, production installation, all nested panes or writers.
- **ALIAS**: the same bounded source/read presentation appears through another Owner entry point; it is not another completed permission.
- **PARTIAL**: an existing capability covers the explicitly named subset; the remainder in the last column is still open.
- **OPEN**: the actual Owner view has no equivalent delegated read integration. No capability name is invented for it.
- **CANDIDATE**: present in a follow-on source batch beyond its named published baseline, with the same limited meaning as IMPLEMENTED.
- **NATIVE UNAVAILABLE**: the Owner navigation itself currently displays an unavailable/placeholder result, not a functioning delegated report.

This is a finite census of the Owner entry points and their named panes/subdialog families at these source references. New navigation must add a row. Row identifiers identify view families, not proposed grants. Read models and business actions are tracked separately. No live POS/Owner/Super Admin sessions were used for this audit; the requested consolidated live checks remain at the end.
