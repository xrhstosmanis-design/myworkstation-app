## Προετοιμασία και όρια

Ο Owner χρησιμοποιεί δική του κανονική προσωπική πρόσβαση, επιτρεπόμενο Διαδόχου Παύλου και τα ήδη ενεργά modules. Η διαδρομή είναι δικό του κατάστημα → Εμπορική λειτουργία → Λοιπές εμπορικές λειτουργίες → Βοηθός Ιδιοκτήτη → Άνοιγμα σελίδας βοηθού. Για ξεχωριστό μη ολοκληρωμένο SuperAdmin δείγμα, η είσοδος παραμένει https://myworkstation-app.onrender.com/platform-admin. Δεν συγχέουμε SuperAdmin support preview με κανονικό Owner.

Πριν από την τελική παρτίδα επιβεβαιώνουμε ξανά τρέχουσα έκδοση/ώρα Ελλάδας/ρόλο/κατάστημα/δικαιώματα και την πραγματική πηγή του επιλεγμένου δείγματος. Οι αναμενόμενοι αριθμοί παρακάτω είναι απογραφή προετοιμασίας, όχι αμετάβλητα δεδομένα ούτε αποτελέσματα του Βοηθού. Ο agent διασταυρώνει τα αρχεία/αναφορές και κάνει την τελική καταγραφή. Όταν ο φυσικός browser δεν είναι διαθέσιμος, ο χρήστης κάνει μόνο την αλληλεπίδραση και παραδίδει τεκμήρια. Ο προηγούμενος περιορισμός native credential browser παραμένει: καμία νέα συνεδρία/runtime/tab/token/private API για παράκαμψη, κανένα αίτημα κωδικών.

Ανάγνωση του κανονικού Owner route και του authorizer: κανονική auth middleware, ενεργή προσωπική συνεδρία, φρέσκος role/company/store έλεγχος, περιορισμένο support context, άδεια και store-paid module ανά απαιτούμενη δυνατότητα. Εντοπίστηκαν υπάρχοντα tests επανεξουσιοδότησης κατά fresh export read/revocation, προσωπικού native history, domain-module/personnel-package και foreign/duplicate/reversed/cap source refusals. Κώδικας/tests ανασκοπήθηκαν· δεν εκτελέστηκε νέο production Owner UI flow και δεν εκτελέστηκε εκ νέου πλήρης σουίτα μόνο για την καταγραφή. Η παρουσία tests δεν υποκαθιστά την παραπάνω πραγματική αποδοχή. Δεν εντοπίστηκε αιτιολογημένη νέα αλλαγή κώδικα σε αυτή την περιορισμένη ανασκόπηση.

## Κλείσιμο παρτίδας

Ο agent συμπληρώνει ανά ID χρόνο/ρόλο/συσκευή/κατάστημα/πραγματική έκδοση όπου διαθέσιμη, ακριβές αποτέλεσμα PASS/FAIL/NOT TESTED, αρχείο/hash και ανεξάρτητη πηγή/χρονισμό. After-only έλεγχος δεν γίνεται πριν/μετά invariant. Κανένα οικονομικό/stock/fiscal/shift/catalog/auth state change. FAIL που χρειάζεται source fix ακολουθεί το υπάρχον claim→CI→guarded release→μόνο αποτυχημένο επανέλεγχο. Το συνολικό VOICE κλείνει μόνο όταν εκπληρωθεί όλο το συμφωνημένο υπόλοιπο ή καταγραφεί ρητά αποδεκτός περιορισμός· CI ή η προετοιμασία δεν αρκούν. Δημοσίευση μαζί checkpoint/manual/active/KAT/pending/tracker/Markdown/PDF, με διατήρηση άλλων owners.
