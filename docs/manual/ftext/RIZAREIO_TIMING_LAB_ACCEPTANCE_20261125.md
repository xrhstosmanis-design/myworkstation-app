# FTEXT #4216 — Αποδοχή συνθετικού LAB και παθητική φυσική μέτρηση μόνο στη Ριζαρείου (25/11/2026)

**Νεότερος επιβεβαιωμένος περιορισμός ιδιοκτήτη:** μόνο το κατάστημα **Ριζαρείου** διαθέτει αυτό το FTEXT+. Δεν διαθέτουμε επιβεβαιωμένη δεύτερη φυσική διασύνδεση FTEXT+/ταμειακής/EFTPOS. Το LAB διαθέτει εικονικές ταμειακές, όχι τεκμηριωμένο αντίστοιχο φυσικό rig. **Δεν απαιτούμε/προσποιούμαστε φυσικό LAB PASS.** Αποδοχή συνθετικού λογισμικού και φυσική παρατήρηση στην παραγωγή είναι διακριτές.

## A. Συνθετικό LAB (χωρίς φυσικό εξοπλισμό)
1. Windows PowerShell 5.1 native smoke tests με μοναδικά προσωρινά directories και συνθετικό driver: instrument OFF και `MWS_FTEXT_LAB_TIMING=1` ON.
2. Επαλήθευση πλήρους πρωτογενούς ατομικής δημοσίευσης, μοναδικού requestId, αμετάβλητου command hash, χωρίς νέα εντολή σε result timeout, lost ack, restart, ανάκτηση, mutex και ανεπίλυτο παλιό αποτέλεσμα.
3. Επιβεβαίωση `publish_to_result_ms` από το **ίδιο** τοπικό μονότονο χρονόμετρο του Windows Connector. Σε πραγματική απουσία αποτελέσματος να καταγράφει `NOT_OBSERVED`, όχι 0. Δεν μετρά φυσική ενεργοποίηση κάρτας: `eftpos_visible_ms=NOT_OBSERVED`.
4. Διατηρούνται PAY, αρχικό journal/handshake, αντιστοίχιση ΦΠΑ, 30s deadline, 200ms polling, no-resend, no double-charge, tenant/POS/serial isolation, logging χωρίς PIN/PAN/tokens/ποσά.
5. Αποτέλεσμα: `SYNTHETIC PASS / PHYSICAL NOT TESTED` όταν όλα τα CI/Windows fixtures επιτύχουν. Το CI PASS δεν συνεπάγεται μειωμένη καθυστέρηση.

## B. Προπαρασκευή παθητικής μέτρησης στη Ριζαρείου — χωριστή έγκριση εγκατάστασης
1. Μόνο μετά από **exact-head full CI + Windows PASS**, review της διαγνωστικής έκδοσης, και **ξεχωριστή ρητή έγκριση** για παραγωγικό Connector. Η εντολή «ξεκίνα» για την προετοιμασία δεν είναι άδεια εγκατάστασης.
2. Πριν από εγκατάσταση: ταυτοποίηση `RIZAREIO-POS-01`, backup/install package hash, επιβεβαιωμένα settings/serial και rollback. Δεν αλλάζουμε ζεύξη, FTEXT+ παραμέτρους, IP, φορολογικούς κωδικούς, καρτέλες ειδών, EFTPOS ρυθμίσεις ή server.
3. Το PR #4222 έχει **υποψήφια αλλά μη εγκατεστημένη** προαιρετική λειτουργία `MWS_FTEXT_RIZAREIO_PASSIVE_TIMING=1`, η οποία επιτρέπεται μόνο για το τριπλό scope storeId `cmvgtyt6d000zh7gtbsp1en3p`, terminalPos `RIZAREIO-POS-01`, serial `DSM24014923`. Είναι **OFF από προεπιλογή**, χρειάζεται exact-head Windows/CI έλεγχο, review και ξεχωριστή έγκριση παραγωγικής εγκατάστασης/ενεργοποίησης. Η `MWS_FTEXT_LAB_TIMING=1` παραμένει αποκλειστικά για συνθετικό LAB και **δεν** ενεργοποιείται στη Ριζαρείου. Ο παθητικός τρόπος μετρά D→F (δημοσίευση αρχείου έως πλήρη ανάγνωση `.res`) και **δεν** παρατηρεί απευθείας την εμφάνιση ποσού στο EFTPOS.
4. Μέτρηση μόνο μέσα από **επόμενες κανονικές πραγματικές συναλλαγές** και μόνο εφόσον υπάρχει ήδη νόμιμη εντολή πελάτη. Ο βοηθός δεν δημιουργεί, επαναλαμβάνει ή ακυρώνει συναλλαγή για δοκιμή. Ένας Connector, καμία χειροκίνητη αλλαγή σε εκκρεμή αρχεία.
5. Για CARD: `A` = πάτημα «Κάρτα» στο POS, `E` = **πρώτη εμφάνιση ποσού στο φυσικό EFTPOS**. Το `A→E` πρέπει να μετρηθεί με **κοινό χρονόμετρο/άμεση παρατήρηση** από τον χειριστή (καμία λήψη PIN/PAN). Ξεχωριστά `D` = publication `.txt`, `F` = ολοκληρωμένη ανάγνωση `.res` από ίδιο Windows stopwatch. Δεν εξισώνουμε `D→F` με `A→E`.
6. Για CASH: καταγράφουμε το πραγματικό `A→H` (έως το τέλος εκτύπωσης) ξεχωριστά από `D→F`.
7. Για κάθε νέο request καταγράφουμε μόνο requestId, elapsed times, status, revision και φυσική παρατήρηση χωρίς προσωπικά/ευαίσθητα δεδομένα. Αβεβαιότητα/χαμένο αποτέλεσμα = fail closed, ποτέ επανάληψη πληρωμής.

## Γ. PASS, HOLD και επόμενη εργασία
- **PASS συνθετικού εργαλείου:** ακριβής Windows/CI έλεγχος και αμετάβλητη φορολογική εκτέλεση.
- **PASS παθητικής διάγνωσης παραγωγής:** μόνο αφού εγκατασταθεί με χωριστή έγκριση η ασφαλής έκδοση και αποδειχθεί επιτόπου η αξιόπιστη καταγραφή των πραγματικών σταδίων. Δεν αποτελεί λύση καθυστέρησης.
- **PASS διόρθωσης 23″:** μόνο μετά από ελεγχόμενη αιτιώδη αλλαγή, νέο CI και πραγματική συγκριτική μέτρηση `A→E` χωρίς αύξηση σφαλμάτων/διπλών κινήσεων.
- **HOLD:** μη επιβεβαιωμένο παραστατικό, εκκρεμές request, μη διαθέσιμη φυσική παρατήρηση, μη ολοκληρωμένο CI, έλλειψη ξεχωριστής έγκρισης εγκατάστασης ή κίνδυνος προσωπικών δεδομένων.
- Το PR #4222 είναι **διάγνωση μόνο**. Δεν περιλαμβάνει επιτάχυνση του EFTPOS, νέο production observer, εγκατάσταση ή φυσικό PASS.
