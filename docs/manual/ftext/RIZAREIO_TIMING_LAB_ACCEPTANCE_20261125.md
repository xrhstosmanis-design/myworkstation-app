# FTEXT #4216 — Ελεγχόμενη αποδοχή χρόνων στο LAB (25/11/2026)

**Κατάσταση:** AWAITING PHYSICAL LAB. Τα Windows synthetic tests και οι δύο αυτοματοποιημένοι έλεγχοι του PR #4222 έχουν δώσει PASS σε προηγούμενο exact head. Το παρόν πρωτόκολλο **δεν** αποτελεί φυσικό LAB PASS ούτε άδεια παραγωγικής εγκατάστασης.

## 1. Προϋποθέσεις — υποχρεωτικά
- ΜΟΝΟ το **ΕΡΓΑΣΤΗΡΙΟ ΔΟΚΙΜΩΝ** με ξεχωριστό, επιβεβαιωμένο φυσικό FTEXT+ / ταμειακή / EFTPOS δοκιμών. Απαγορεύεται σύνδεση σε παραγωγικό RIZAREIO-POS-01, πραγματικό τραπεζικό EFTPOS ή άλλα καταστήματα.
- Read-only απογραφή 25/11: LAB έχει δύο **εικονικές** ταμειακές (LAB-POS-01/02), μηδέν FtextCashRequest ιστορικά και δεν τεκμηριώθηκε FTEXT connector. Η ύπαρξη φυσικού δοκιμαστικού rig **ΔΕΝ ΕΧΕΙ ΕΠΙΒΕΒΑΙΩΘΕΙ**. Δεν ξεκινά φυσική δοκιμή μέχρι την επιβεβαίωσή του.
- Επικύρωση ακριβούς revision Windows package, σωστού storeId/terminalPos/settingsHash, εργαστηριακού profile και sandbox EFTPOS. Η ενεργοποίηση `MWS_FTEXT_LAB_TIMING=1` επιτρέπεται μόνο στον ελεγχόμενο εργαστηριακό Connector.
- Καμία επανάληψη προηγούμενης απόδειξης/πληρωμής για αναπαραγωγή. Καμία τροποποίηση token, IP, timeout, PAY command, retry, no-resend ή αντιστοίχισης ΦΠΑ. Ένας Connector ανά τερματικό.

## 2. Μονάδες μέτρησης
- **A:** το πάτημα ολοκλήρωσης στο POS (υπολογιστής POS).
- **B:** cloud request created (server clock/domain).
- **C:** dispatch claimed / connector poll (server/connector clocks χωριστά).
- **D:** ολοκληρωμένη ατομική δημοσίευση `.txt` (μονοτονικό χρονόμετρο του Connector).
- **E:** οθόνη φυσικού EFTPOS **πρώτη φορά εμφανίζει το ποσό** (εξωτερική παρατήρηση με κοινό ρολόι/βίντεο που δεν αποθηκεύει PAN/PIN).
- **F:** πλήρης ανάγνωση `.res` (μονοτονικό χρονόμετρο του Connector).
- **G:** server acknowledgment/SALE_COMMITTED (server clock).
- **H:** φυσική ολοκλήρωση εκτύπωσης μετρητών, εφόσον γίνεται επιτρεπτή εργαστηριακή έκδοση.
- **Κρίσιμη μετρική CARD:** A→E σε **ένα και το ίδιο** αξιόπιστο χρονόμετρο/βίντεο. Δεν υποκαθίσταται από A→G ή D→F. **Μετρική FTEXT:** D→F από το `FTEXT_LAB_TIMING` (μόνο όταν είναι έγκυρη και αρχική δημοσίευση).
- Διαφορετικά μονοτονικά ρολόγια POS/server/Windows δεν αφαιρούνται μεταξύ τους. Άγνωστο E σημαίνει `NOT_OBSERVED`, όχι `0`.

## 3. Επιτρεπτή διαδικασία
1. Πριν από φυσικό rig: εκτέλεση Windows synthetic fixture με instrument OFF και ON, έλεγχος ίδιου αρχικού fiscal command hash/μη επανέκδοσης και ακριβούς αποτελέσματος `FTEXT_LAB_TIMING`. Μόνο synthetic ροή, χωρίς φυσική/τραπεζική χρέωση.
2. Μετά τη βεβαιωμένη εργαστηριακή διασύνδεση, καταγραφή μίας **νέας, εγκεκριμένης εργαστηριακής** συναλλαγής ανά σενάριο, με μοναδικό requestId και μετρημένο A→E ή A→H. Απαγορεύεται πραγματική χρέωση πελάτη για testing.
3. Σενάρια: 1 είδος CASH, 1 είδος CARD σε sandbox και (μόνο όπου επιτρέπεται) 3 είδη CARD. Καταγράφονται πριν/μετά χωρίς αλλαγή κωδικών ΦΠΑ.
4. Προσομοίωση (όχι σε πραγματικό ταμείο): καθυστερημένου/χαμένου `.res`, διπλού poll, lost acknowledgment, restart, ενεργού mutex. Επιβεβαίωση μη επανέκδοσης `.txt`, μη διπλής πληρωμής/stock και αμετάβλητων durable evidence.
5. Σύγκριση baseline vs instrumentation-off vs instrumentation-on, με ίδιες συνθήκες, φυσικό χρόνο A→E, D→F και σαφείς αποκλίσεις. Μη εξαγωγή αιτιότητας μόνο από τοπικό `.res`.

## 4. PASS / FAIL
- **PASS μόνο για διαγνωστική καταγραφή:** ασφαλής προαιρετική συλλογή χωρίς payload/PIN/κάρτες/μυστικά, σωστά χρονομετρικά πεδία και αμετάβλητη φυσική / συνθετική λειτουργία. Χωρίς φυσικό rig, γράφουμε μόνο `SYNTHETIC PASS — PHYSICAL NOT TESTED`.
- **PASS για λύση καθυστέρησης 23s:** μόνο μετά από πραγματική εργαστηριακή A→E μέτρηση πριν/μετά, αποδεδειγμένη μείωση, και πλήρη έλεγχο ασφαλείας. Το PR #4222 **δεν περιέχει αλλαγή που επιταχύνει πληρωμές**.
- **FAIL / HOLD:** αν η οθόνη EFTPOS, οι χρόνοι ή οι οικονομικές/φορολογικές συνέπειες δεν παρατηρούνται αξιόπιστα ή αν λείπει φυσικό rig. Καμία αυτόματη μετάπτωση σε παραγωγή.

## 5. Αναφορά
Καταγράφουμε revision, store=LAB, fixture/rig ID, requestId χωρίς προσωπικά στοιχεία, είδος πληρωμής, A→E/H, D→F, end state και ένα τεκμήριο φυσικής παρατήρησης χωρίς μυστικά. Φυσικό EFTPOS test, merge και guarded release παραμένουν χωριστές εγκρίσεις.
