# Κέντρο Εκκρεμοτήτων Chat — ιστορικό PASS

Πηγή: `CHECKPOINTS/CHANGES/2026-09-12-pending-center-chat.md`, #751 / CI1916 / merge9080739a. Συμφιλίωση01/10, χωρίς νέα LAB δοκιμή.

## Πρόσβαση και χρήση

Ιδιοκτήτης με ενεργό PENDING_CENTER ή Super Admin σε ενεργό εταιρικό context. Υπάλληλος αποκλείεται server-side. Στο BackOffice ανοίξτε «Εμπορική λειτουργία» → «Κέντρο Εκκρεμοτήτων».

1. Επιλέξτε κατάστημα ή «Όλα τα καταστήματα» της ενεργής εταιρείας.
2. Επιλέξτε Ανοιχτές, Ολοκληρωμένες ή Όλες.
3. Δείτε κείμενο, κατηγορία, αποστολέα και ημερομηνία της συνδεδεμένης εκκρεμότητας Chat.
4. «Κλείσιμο» και «Επαναφορά» ενημερώνουν την ίδια εκκρεμότητα στον server. Κρατούν χειριστή, χρόνο και Audit. Δεν δημιουργούν δεύτερο task.
5. «Ανανέωση» φορτώνει την τρέχουσα εικόνα.

## Όρια και αντιμετώπιση

Το παλιό PASS αφορά μόνο το παραπάνω Κέντρο Chat. Δεν αποδεικνύει σημερινή live δοκιμή, πρόσθετη διαχείριση/ανάθεση μέσα στο Chat, Push ή ενιαία οικονομική/stock ουρά. Τα #16/#17 παραμένουν χωριστά OPEN.

Αν η καρτέλα είναι κλειδωμένη, ελέγξτε ενεργό module και ρόλο. Αν δεν εμφανίζονται εγγραφές, ελέγξτε εταιρεία, κατάστημα και φίλτρο κατάστασης. Σφάλμα φόρτωσης χρειάζεται επανέλεγχο· δεν σημαίνει ολοκλήρωση εκκρεμοτήτων. Μην επαναλαμβάνετε παλιές μεταβολές για τεκμηρίωση.
