# Δημοσίευση ελεγμένης έκδοσης - περιορισμένο LIVE PASS 08/10/2026

Χρήση από τους ήδη εξουσιοδοτημένους διαχειριστές του κοινού GitHub repository και της υπηρεσίας Render. Οι χειριστές POS δεν αλλάζουν αυτές τις ρυθμίσεις. Η ροή δεν προσθέτει δικαιώματα, πρόσβαση εταιρείας/καταστήματος ή άδειες modules.

Δοκιμασμένη ροή:

1. Δημοσίευση αλλαγής στο κοινό main μετά από επιτυχές CI του PR. Το CI του main ολοκληρώνει επιτυχώς το πλήρες build-and-test για την ίδια έκδοση.
2. Το υπάρχον GitHub workflow «Deploy MyWorkStation to Render» ελέγχει αυτή την έκδοση, διατηρεί το προηγούμενο υγιές revision ως rollback artifact και ζητά τη συγκεκριμένη SHA από το Render.
3. Επιβεβαίωση στο Render ότι η συγκεκριμένη έκδοση είναι LIVE και στο /api/health ότι ok=true και revision ταυτίζεται. Η πραγματική ρύθμιση Auto-Deploy πρέπει να είναι Off.
4. Μία αλλαγή μόνο σε έγγραφα ολοκληρώνει το ελαφρύ CI, παραλείπει το βήμα deployment και δεν δημιουργεί νέο Render deploy. Η ήδη ενεργή επαλήθευση έκδοσης συνεχίζεται.

Το αρχικό merge της νέας πολιτικής χρησιμοποίησε [skip render] για τη μετάβαση από την παλιά ρύθμιση.

Κριτήριο αυτού του περιορισμένου PASS: ένα deployment της ελεγμένης έκδοσης, πραγματικό Off, ακριβής υγιής revision και καμία επανεγκατάσταση από την παρατηρημένη αλλαγή εγγράφων. Η δοκιμή δεν περιλαμβάνει πωλήσεις, πληρωμές, stock, φυσικό POS timing ή χωρητικότητα100καταστημάτων. Τα σενάρια παλιού/rerun workflow και σφάλματος δικτύου ελέγχθηκαν απομονωμένα· δεν έγινε ζωντανή εισαγωγή σφάλματος ή δοκιμή rollback. Εξωτερικά/manual deployments και νέα ενεργοποίηση Auto-Deploy μπορούν να παρακάμψουν αυτή την πολιτική.

Αν υπάρχει αβέβαιο αποτέλεσμα hook ή δεν εμφανιστεί η αναμενόμενη έκδοση, ο διαχειριστής ελέγχει πρώτα το ιστορικό Render και το διατηρημένο rollback artifact. Δεν επαναλαμβάνει τυφλά το αίτημα deployment και δεν ζητά επανάληψη συναλλαγής από το POS για τη διάγνωση. Χωρητικότητα, ενεργές εργασίες κατά τερματισμό και αποκατάσταση από βλάβη παραμένουν χωριστοί έλεγχοι.
