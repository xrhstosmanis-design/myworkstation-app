# MyWorkStation — Κεντρικό Εγχειρίδιο

Αυτός είναι ο μόνιμος φάκελος πηγής για το τελικό εγχειρίδιο MyWorkStation.

## ΚΑΝΟΝΑΣ PASS → MANUAL

Από 20/09/2026 ισχύει υποχρεωτικά:

1. Κάθε λειτουργία/module που λαμβάνει πραγματικό **LAB PASS**, **LIVE PASS** ή **USER PASS** καταγράφεται στο `docs/manual/` στην αντίστοιχη ενότητα.
2. Το manual ενημερώνεται μαζί με το checkpoint/active list, όχι στο τέλος του project.
3. **CI PASS μόνο του δεν είναι LAB PASS** και δεν αρκεί για να χαρακτηριστεί λειτουργία ολοκληρωμένη στο εγχειρίδιο.
4. Checkpoints με **FAIL**, **AWAITING LAB**, **RETEST**, **OPEN** ή ανοιχτή εκκρεμότητα δεν παρουσιάζονται ως ολοκληρωμένες λειτουργίες.
5. Αν νεότερο checkpoint αναιρεί παλιότερο PASS, το manual ενημερώνεται με το νεότερο πραγματικό status.
6. Οι οδηγίες πρέπει να περιγράφουν μόνο τη δοκιμασμένη ροή και τα πραγματικά όρια της λειτουργίας.
7. Κάθε ολοκληρωμένο module κρατά: χρήση, βήματα, δικαιώματα/ασφάλεια, PASS criteria και troubleshooting όπου απαιτείται.
8. Στο τέλος του MyWorkStation οι ενότητες του `docs/manual/` θα αποτελέσουν την πηγή για το ενιαίο PDF/εγχειρίδιο.
9. Το `docs/manual/` είναι η επίσημη πηγή αλήθειας για ολοκληρωμένα PASS. Παλιότερα `AWAITING LAB` μέσα στην ιστορική ενεργή λίστα δεν αναιρούν νεότερο πραγματικό PASS που έχει καταγραφεί εδώ.
10. Κάθε σελίδα/agent που λαμβάνει πραγματικό PASS ενημερώνει στο ίδιο PR: checkpoint, κεντρική ενεργή λίστα και `docs/manual/<module>/PASS.md`.
11. Η εγγραφή PASS περιλαμβάνει υποχρεωτικά δικαιώματα, σημείο πρόσβασης, δοκιμασμένα βήματα χρήσης, όρια ασφαλείας, κριτήρια PASS και troubleshooting.
12. Πριν αρχίσει νέα εργασία, ελέγχεται πρώτα το σχετικό `PASS.md`, ώστε να μην ξαναγίνεται ήδη ολοκληρωμένη λειτουργία.
