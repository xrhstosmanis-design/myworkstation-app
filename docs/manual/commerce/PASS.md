# Εμπορικά modules — περιορισμένη αποδοχή πλοήγησης

Εξουσιοδοτημένος Super Admin με υφιστάμενη πρόσβαση στο επιλεγμένο κατάστημα ανοίγει https://myworkstation-app.onrender.com/platform-admin → Καταστήματα → ΕΡΓΑΣΤΗΡΙΟ ΔΟΚΙΜΩΝ → Πλήρες BackOffice → Λοιπές εμπορικές λειτουργίες → Εμπορικές λειτουργίες.

Τα μεγάλα επάνω κουμπιά ανοίγουν τις λειτουργίες. Το Modules επιστρέφει στην αρχική προβολή. Οι μικρότερες κάτω κάρτες δείχνουν μόνο ΕΝΕΡΓΟ/ΔΙΑΘΕΣΙΜΟ/ΚΛΕΙΔΩΜΕΝΟ· δεν αλλάζουν άδειες και δεν αποτελούν κουμπιά ενεργοποίησης. Ελέγξτε το Κατάστημα πριν χρησιμοποιήσετε οποιαδήποτε λειτουργία. Σε μεγιστοποιημένο παράθυρο κυλήστε το εσωτερικό περιεχόμενο μέχρι την τελευταία κάρτα· ο τίτλος και τα επάνω χειριστήρια παραμένουν προσβάσιμα.

Για μετάβαση από Τιμοκατάλογο σε Χειριστές πατήστε απευθείας Χειριστές μία φορά. Η λίστα πρέπει να εμφανιστεί αμέσως μετά τη φόρτωση, χωρίς ενδιάμεση επιστροφή στα Modules. Η μετάβαση και η επιστροφή δεν υποβάλλουν αλλαγές τιμών ή δικαιωμάτων. Σε παλιά έκδοση/κρυμμένο περιεχόμενο ανανεώστε την εφαρμογή και ανοίξτε ξανά το ίδιο κατάστημα. Μην υποβάλετε φόρμα, αλλάξετε PIN ή επαναλάβετε συναλλαγή για έλεγχο εμφάνισης.

Η πραγματική αποδοχή αφορά desktop LAB / Super Admin, 22 προορισμούς κουμπιών και διάκριση λειτουργιών από κατάσταση, καθώς και τη διορθωμένη άμεση μετάβαση Τιμοκατάλογος → Χειριστές. Δεν αποτελεί αποδοχή αλλαγής δικαιωμάτων, λογαριασμού περιορισμένου ρόλου, απενεργοποιημένου module, άλλης εταιρείας/καταστήματος, φυσικού tablet/scanner/camera, υπολογισμών αναφορών ή οικονομικών/stock πράξεων. Οι προηγούμενες αποδοχές απογραφής/Excel/τιμών/προσφορών/κύλισης αναλύσεων διατηρούνται χωριστά.
