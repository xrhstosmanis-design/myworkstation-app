# Backup - περιορισμένο LIVE PASS 19/10/2026

Δικαιούχοι: Super Admin για το υπάρχον monitoring του MyWorkStation και εξουσιοδοτημένος διαχειριστής του συγκεκριμένου Render workspace για εκτέλεση. Δεν δίνονται νέα δικαιώματα. Πρόκειται για platform-level αντίγραφο βάσης, όχι προβολή ή αλλαγή δεδομένων άλλου καταστήματος από χειριστή POS.

## Επιβεβαιωμένη ροή

1. Ελέγξτε το τελευταίο full backup στο monitoring: run ID, ώρα, κατάσταση, bytes, SHA-256, revision και archive dry-run.
2. Ο cron εκτελεί /backup/run-jobs.sh ανά πέντε λεπτά. Μόνο οι οκτώ καθορισμένες UTC ώρες δημιουργούν προγραμματισμένο full backup. Ένα NOT_ENROLLED/επιτυχές πεντάλεπτο δεν αποδεικνύει full backup.
3. Για τη συγκεκριμένη αποδοχή, ο εξουσιοδοτημένος διαχειριστής άνοιξε το υπάρχον Render Web Shell του myworkstation-db-backup και εκτέλεσε μία φορά το εγκατεστημένο /backup/run-backup.sh. Δεν αλλάχτηκε πρόγραμμα ή ρύθμιση και δεν πατήθηκε Trigger Run.
4. Η ροή έστειλε STARTED, δημιούργησε ένα archive, έλεγξε το TOC, το ανέβασε κρυπτογραφημένο, επαλήθευσε μέγεθος και κατέγραψε SUCCEEDED. Μόνο το upload χρησιμοποιεί standard SDK retries έως8συνολικές προσπάθειες ανά αίτημα. Δεν επαναλαμβάνεται το dump ή όλο το upload. Εξαντλημένα retries διατηρούν UPLOAD_FAILED.
5. Η ανεξάρτητη λήψη του ίδιου αποθηκευμένου object πέρασε SHA-256, byte size, pg_restore --list με table entries και HeadObject AES256. Η προσωρινή λήψη καθαρίστηκε, το αρχικό off-site backup διατηρήθηκε.

## Αντιμετώπιση αποτυχίας

Ελέγξτε το ακριβές errorCode και τα logs του συγκεκριμένου run. STARTED δεν είναι επιτυχία. Με UPLOAD_FAILED το archive δεν θεωρείται ασφαλές. Μην ξεκινάτε δεύτερο dump όσο η πρώτη εκτέλεση είναι ενεργή ή το αποτέλεσμα άγνωστο. Μην αλλάζετε bucket, encryption, schedule ή credentials για να παρακάμψετε το σφάλμα. Πλήρης δοκιμή επαναφοράς ανήκει στην ξεχωριστή συμφωνημένη διαδικασία ανάκτησης.
