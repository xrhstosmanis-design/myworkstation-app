# MyWorkStation — Παραγγελίες & Αγορές Kiosk Flow

Μόνιμη λειτουργική προδιαγραφή για το module Παραγγελίες & Αγορές, βασισμένη στα screenshots Kiosk Manager που δόθηκαν στις 09/08/2026.

## Βασικός κανόνας

Η ροή παραγγελίας είναι ξεχωριστή από τα φορολογικά/εγκεκριμένα παραστατικά αγοράς. Οι επεξεργάσιμες παραγγελίες αποθηκεύονται σε `PurchaseOrder` / `PurchaseOrderLine`. Τα υπάρχοντα `PurchaseDocument` / `PurchaseDocumentLine` δεν επαναχρησιμοποιούνται ως editable order ledger και δεν διαγράφονται/αλλοιώνονται από τη νέα λειτουργία.

## Drill-downs

1. Μολύβι δίπλα στο α/α → `Διόρθωση εγγραφής παραγγελίας`.
2. Κλικ σε κωδικό ή περιγραφή → `Διόρθωση κωδικού τιμολογίου`.
3. Κλικ σε barcode → `Εναλλακτικοί κωδικοί Barcodes είδους`.

## Διόρθωση γραμμής

Πεδία:
- ποσότητα με - / +
- τιμή μονάδος
- ΔΩΡΟ
- έκπτωση 1 / 2 / 3
- σύνολο ΕΦΚ
- ΦΠΑ
- τελική αγορά / μονάδα
- σύνολο χωρίς ΦΠΑ
- σύνολο με ΦΠΑ
- MarkUp %
- Νέα Λιανική

### Αμφίδρομος υπολογισμός

Μετά τις διαδοχικές εκπτώσεις:

`τελική καθαρή μονάδα = τιμή μονάδος × (1-εκπτ1) × (1-εκπτ2) × (1-εκπτ3)`

`καθαρό σύνολο = τελική καθαρή μονάδα × ποσότητα`

`βάση ΦΠΑ = καθαρό σύνολο + ΕΦΚ`

`σύνολο με ΦΠΑ = βάση ΦΠΑ × (1 + ΦΠΑ%)`

`κόστος με ΦΠΑ ανά μονάδα = σύνολο με ΦΠΑ / ποσότητα`

MarkUp → Νέα Λιανική:

`νέα λιανική = κόστος με ΦΠΑ ανά μονάδα × (1 + MarkUp%)`

Νέα Λιανική → MarkUp:

`MarkUp% = (νέα λιανική / κόστος με ΦΠΑ ανά μονάδα - 1) × 100`

Οι δύο υπολογισμοί εκτελούνται με ξεχωριστά πραγματικά κουμπιά και η αποθήκευση γράφει το αποτέλεσμα στη γραμμή.

## Κωδικός τιμολογίου / προϊόν

Η καρτέλα επιτρέπει:
- supplier/invoice code
- περιγραφή
- τρέχουσα λιανική
- κύριο barcode

Όταν υπάρχει πραγματικό `productId`, η αλλαγή ονομασίας/λιανικής/barcode συνδέεται με το πραγματικό προϊόν του ίδιου tenant.

## Εναλλακτικά barcodes

Υποστηρίζονται:
- λίστα barcodes
- πώληση
- συσκευασία (`unitMultiplier`)
- τιμή τεμαχίου
- ονομασία
- ενημέρωση
- νέο barcode
- επεξεργασία
- διαγραφή

Δεν επιτρέπεται barcode που χρησιμοποιείται ήδη από άλλο προϊόν της ίδιας εταιρείας.

## Κουμπιά παραγγελίας

- Επιστροφή
- Νέο είδος
- Διαγραφή όλων των γραμμών
- Οριστικοποίηση
- Αποστολή email στον πραγματικό email προμηθευτή
- Τιμολόγηση (status `INVOICED` μετά από `FINAL`)
- Excel / CSV

Η τιμολόγηση της παραγγελίας δεν αποτελεί φορολογική μετάδοση και δεν αλλάζει Kiosk Manager/RBS/CapDriver.

## Πρόταση παραγγελίας / alarm Stock

Χρησιμοποιούνται μόνο πραγματικά:
- `StoreProduct.currentStock`
- `StoreProduct.minStock`
- ιστορικό `PurchaseDocumentLine` / `PurchaseDocument`

Πρόταση ποσότητας:

`max(minStock - currentStock, 0)`

Ο τελευταίος προμηθευτής και τελευταίο κόστος εμφανίζονται μόνο όταν υπάρχουν πραγματικές προηγούμενες αγορές.
