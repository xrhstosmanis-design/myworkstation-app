# KAT TEST — Golden State

Το KAT TEST δεν πρέπει να εξαρτάται από browser state, localStorage ή ανοιχτή σελίδα.

## Μόνιμη πηγή αλήθειας

Η βασική κατάσταση αποθηκεύεται server-side στη βάση ως `KatTestGoldenSnapshot` και περιλαμβάνει:

- πραγματικό κατάστημα ΚΑΤ που χρησιμοποιήθηκε ως πηγή,
- δημοσιευμένο POS layout και version,
- κατηγορίες,
- προϊόντα,
- barcodes,
- τιμές καταστήματος,
- stock/min stock.

Το KAT TEST επαναφέρεται από αυτό το snapshot. Το κλείσιμο browser, logout ή αλλαγή υπολογιστή δεν διαγράφει τη βασική κατάσταση.

## Ροή

1. Super Admin πατά «Συγχρονισμός από ΚΑΤ» μόνο όταν θέλει νέα επίσημη βάση.
2. Δημιουργείται νέα server-side έκδοση snapshot από το πραγματικό ΚΑΤ.
3. Το snapshot αντιγράφεται στο απομονωμένο `kat-test-company / kat-test-store`.
4. Οι δοκιμές γίνονται στους 3 ρόλους χωρίς αλλαγή του πραγματικού ΚΑΤ.
5. Σε επανεκκίνηση ή νέα συνεδρία, η βάση επαναφέρεται από το αποθηκευμένο snapshot — όχι από μνήμη browser.

## Κανόνας ανάπτυξης

Δεν ξανασχεδιάζουμε το POS από την αρχή για το KAT TEST. Χρησιμοποιούμε το εγκεκριμένο Store POS runtime και το δημοσιευμένο layout του πραγματικού ΚΑΤ. Οι αλλαγές γίνονται πάνω στην υπάρχουσα κατάσταση και περνούν από versioned PR/CI.
