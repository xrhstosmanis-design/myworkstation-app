# TEST — Μόνιμη βάση ανάπτυξης MyWorkStation

Από εδώ και πέρα υπάρχει **ένα μόνο δοκιμαστικό περιβάλλον: TEST**.

Το TEST δεν είναι αντίγραφο πραγματικού καταστήματος και δεν υπάρχει «πραγματικό ΚΑΤ» ως πηγή. Είναι το μόνιμο περιβάλλον πάνω στο οποίο εξελίσσουμε όλο το MyWorkStation μέχρι να ολοκληρωθεί η εμπορική έκδοση.

## Κανόνας διατήρησης

Δεν ξαναστήνουμε το πρόγραμμα από την αρχή. Κάθε νέα αλλαγή πατάει πάνω στην υπάρχουσα κατάσταση του TEST.

Πρέπει να διατηρούνται:

- POS layout και κουμπιά,
- κατηγορίες,
- προϊόντα και barcodes,
- τιμές και stock,
- χρήστες και ρόλοι,
- βάρδιες και Έλεγχος Ταμείου,
- modules και ρυθμίσεις,
- όλη η εμπορική λειτουργία που έχει ήδη ολοκληρωθεί.

Το κλείσιμο browser, logout, restart ή αλλαγή υπολογιστή δεν αποτελεί reset του TEST.

## Μόνιμη αποθήκευση

Η ενεργή κατάσταση βρίσκεται στη server-side βάση του TEST. Επιπλέον μπορεί να αποθηκεύεται versioned `TestStateSnapshot` ως σημείο επαναφοράς πριν από σημαντικές αλλαγές.

## Ροή ανάπτυξης

1. Δουλεύουμε πάνω στο υπάρχον TEST.
2. Πριν από σημαντική αναβάθμιση κρατάμε snapshot/backup.
3. Προσθέτουμε ή διορθώνουμε μόνο το ζητούμενο κομμάτι.
4. Ελέγχουμε Super Admin, Admin και Πωλητή στο ίδιο TEST.
5. Δεν δημιουργούμε δεύτερο προσωρινό POS ή δεύτερο κατάστημα για να λύσουμε πρόβλημα.
6. Όταν το TEST ολοκληρωθεί και σταθεροποιηθεί, η ίδια βάση λειτουργιών γίνεται η εμπορική έκδοση MyWorkStation που εγκαθίσταται σε οποιοδήποτε κατάστημα.

## Μελλοντικά πραγματικά καταστήματα

Κάθε πραγματικό κατάστημα θα είναι πελάτης/tenant του ολοκληρωμένου MyWorkStation. Θα παίρνει το σταθερό πρόγραμμα και τις δικές του ρυθμίσεις, προϊόντα, χρήστες και σύνδεση ταμειακής/connector όπου απαιτείται.
