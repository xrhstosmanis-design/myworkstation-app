# MyWorkStation — Kiosk Manager Backoffice Reference

Αυτό είναι το μόνιμο reference για τη μετάβαση πελατών από Kiosk Manager στο MyWorkStation.

## Κεντρική αρχή
Οι πελάτες που θα χρησιμοποιήσουν το MyWorkStation είναι ήδη εξοικειωμένοι με Kiosk Manager. Στόχος είναι μικρή καμπύλη εκμάθησης: γνώριμη δομή, γνώριμες ονομασίες και γνώριμες ροές, με πιο σύγχρονο UI και περισσότερες δυνατότητες.

Δεν αντιγράφουμε τυφλά την παλιά εμφάνιση, αλλά κρατάμε τη λογική εργασίας και τη χωροθέτηση που ο χρήστης ήδη καταλαβαίνει.

## Κανόνας σχεδίασης MyWorkStation
Το νέο Backoffice πρέπει να μοιάζει λειτουργικά με Kiosk Manager ώστε ο υπάρχων χρήστης να αναγνωρίζει αμέσως:
- πού είναι οι Κατηγορίες,
- πού είναι οι Υποκατηγορίες,
- πού είναι η Καρτέλα είδους,
- πού αλλάζει Τιμή / ΦΠΑ / Απόθεμα,
- πού είναι τα Barcodes,
- πού είναι οι Χειριστές και τα Δικαιώματα,
- πού είναι Παραστατικά / κινήσεις / αναφορές.

Το MyWorkStation μπορεί να είναι πιο καθαρό, responsive και σύγχρονο, αλλά δεν αλλάζουμε χωρίς λόγο τη βασική νοητική διαδρομή του Kiosk Manager.

## Master Catalog / μαζική διαχείριση
Για Super Admin, η λίστα προϊόντων πρέπει να μπορεί να παρουσιαστεί με Kiosk Manager-style πίνακες και ομαδοποίηση:
- Ομάδα,
- Προϊόν,
- ΦΠΑ / Τμήμα ΦΠΑ,
- Κατηγορία,
- Υποκατηγορία,
- Εταιρεία / Brand,
- Προμηθευτής,
- Barcode / εσωτερικός κωδικός,
- Τιμή λιανικής,
- Τιμή αγοράς / κόστος,
- Απόθεμα,
- ενεργό / ανενεργό.

Ο Super Admin πρέπει να μπορεί από αυτή τη γνώριμη λίστα να κάνει μαζική επιλογή και ενεργοποίηση προϊόντων προς TEST/κατάστημα.

## Απαράβατος κανόνας
Πριν γίνει redesign Backoffice ή αλλαγή στις οθόνες προϊόντων/αποθήκης/δικαιωμάτων/παραστατικών, διαβάζεται πρώτα αυτό το αρχείο. Τα παραπάνω Kiosk Manager screenshots είναι η σωστή reference βάση — όχι τα προηγούμενα MyWorkStation mockups.
