# Προμηθευτές — Kiosk-style baseline

Η ενότητα Προμηθευτών ακολουθεί τη λειτουργική λογική των screenshots 09/08/2026 χωρίς να αντιγράφει το παλιό design αυτούσιο.

## Κύρια tabs
- Κατάλογος προμηθευτών
- Τιμολόγια
- Πληρωμές
- Αγορές
- Πωλήσεις

## Κατάλογος
Πεδία: κωδικός, επωνυμία, λειτουργικό υπόλοιπο, ΑΦΜ, παρατηρήσεις, τζίρος τρέχοντος/προηγούμενου έτους, κατάσταση, κατηγορία, διεύθυνση χρέωσης.

Το υπόλοιπο είναι λειτουργικό: εγκεκριμένες αγορές + διορθώσεις υπολοίπου - πραγματικές συνδεδεμένες πληρωμές. Δεν παρουσιάζεται ως λογιστικά επιβεβαιωμένο υπόλοιπο τρίτου συστήματος.

## Μολύβι
Ανοίγει «Διόρθωση στοιχείων Προμηθευτή» με tabs:
1. Βασικά στοιχεία
2. Διευθύνσεις
3. Business Units
4. Λοιπά

## Δεξί κλικ / touch long press
Δεξί κλικ ή συνεχόμενο άγγιγμα ~650ms ανοίγει το menu ενεργειών.

Βασικές ενέργειες:
- Διόρθωση στοιχείων
- Μεταφορά/προβολή ειδών ή κωδικών
- Πληρωμή
- Διόρθωση υπολοίπου
- Τιμολογήσεις μήνα
- Τιμολογήσεις έτους
- Λογιστική καρτέλα
- Νέα παραλαβή / αγορά
- Νέο τιμολόγιο μόνο αξιών
- Προβολή ειδών
- Απενεργοποίηση προμηθευτή χωρίς διαγραφή ιστορικού

## Touch keyboard
Κάθε νέο πεδίο text/search/email/tel/password/url/number και textarea που δημιουργεί το MyWorkStation είναι touch-enabled. Σε touch pointer εμφανίζεται in-app keyboard, ενώ σε mouse/physical keyboard δεν ανοίγει αυτόματα. Date/select/file/checkbox/radio παραμένουν native controls.

## Πηγές δεδομένων
- Supplier
- PurchaseDocument / PurchaseDocumentLine
- StoreTransaction
- SupplierBalanceAdjustment
- Sale / SaleLine
- StoreProduct
- Store

Δεν εφευρίσκονται οικονομικές τιμές ή φορολογικά στοιχεία.
