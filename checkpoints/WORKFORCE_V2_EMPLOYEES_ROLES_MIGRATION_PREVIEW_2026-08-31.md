# CHECKPOINT — Workforce v2: Εργαζόμενοι, Ρόλοι & Προεπισκόπηση Μεταφοράς

Ημερομηνία: 31/08/2026

## Στόχος

Δεύτερο ασφαλές checkpoint του νέου module **«Προσωπικό & Πρόγραμμα»**, μετά τη βάση του PR #403.

Η υλοποίηση παραμένει ανεξάρτητη από το παλιό module. Το παλιό `Employee / ShiftType / Schedule` χρησιμοποιείται μόνο ως πηγή ανάγνωσης για προεπισκόπηση μεταφοράς. Δεν εκτελείται αυτόματη αντιγραφή, αλλαγή ή διαγραφή δεδομένων.

## Περιλαμβάνει

- λειτουργικό API `Workforce v2` για εργαζομένους,
- δημιουργία, ανάγνωση, επεξεργασία και ενεργοποίηση/απενεργοποίηση εργαζομένου,
- ρόλους / θέσεις ανά ιδιοκτήτη,
- δημιουργία, επεξεργασία και ασφαλή ενεργοποίηση/απενεργοποίηση ρόλου,
- έναν ή περισσότερους ρόλους ανά εργαζόμενο και υποχρεωτικό κύριο ρόλο,
- κατάστημα βάσης,
- πρόσβαση εργαζομένου σε πολλά καταστήματα,
- έλεγχο ότι όλα τα καταστήματα και οι ρόλοι ανήκουν στον ίδιο ιδιοκτήτη,
- περιορισμό ιδιοκτήτη μόνο στα δικά του καταστήματα με ενεργό `PERSONNEL_BASIC` ή ανώτερο πακέτο,
- ωρομίσθιο με ημερομηνία ισχύος ή σταθερό μηνιαίο ποσό,
- ιστορικό αλλαγών ωρομισθίου,
- μέγιστες ημέρες / ώρες και ελάχιστα ρεπό,
- διαθεσιμότητα πρωί / απόγευμα / βράδυ / Σαββατοκύριακο,
- πλήρες `WorkforceAuditLog` για κάθε μεταβολή,
- υποχρεωτική προεπισκόπηση και `confirmed: true` πριν από κάθε εγγραφή,
- νέα οθόνη μέσα στο κέντρο Super Admin.

## Προεπισκόπηση μεταφοράς παλιών εργαζομένων

Το endpoint:

`POST /api/platform/store-modules/companies/:companyId/stores/:storeId/workforce-v2/migration/preview`

επιστρέφει μόνο πρόταση αντιστοίχισης με:

- `READY`,
- `NEEDS_REVIEW`,
- `ALREADY_LINKED`,
- `BLOCKED`,
- πιθανό ρόλο,
- πιθανό διπλότυπο,
- προτεινόμενο κατάστημα βάσης και πρόσβαση,
- προτεινόμενη διαθεσιμότητα,
- σταθερό `previewHash`.

Ρητές δικλείδες:

- `mode: PREVIEW_ONLY`,
- `readOnly: true`,
- `applyAvailable: false`,
- `applyEndpoint: null`,
- δεν υπάρχει route `/migration/apply`,
- δεν υπάρχει κουμπί εφαρμογής στο UI.

## Δικαιώματα

- **Platform Super Admin:** πλήρης πρόσβαση σε όλους τους ιδιοκτήτες και τα καταστήματα.
- **Owner / Admin / Manager:** μόνο στην εταιρεία του και μόνο σε καταστήματα με ενεργό πακέτο προσωπικού.
- **Άλλος ρόλος / Store Operator:** απορρίπτεται.
- Τα endpoints ενεργοποίησης και τιμολόγησης των πακέτων παραμένουν αποκλειστικά για Super Admin.

## Δοκιμές

- 6 δοκιμές καθαρής λογικής και source contracts,
- ελληνική κανονικοποίηση ρόλων,
- αντιστοίχιση διαθεσιμότητας από παλιές βάρδιες,
- έλεγχος πιθανών διπλοτύπων,
- αναγνώριση ήδη συνδεδεμένου εργαζομένου,
- έλεγχος ότι το preview δεν μεταβάλλει το input,
- πραγματικό HTTP E2E με PostgreSQL για Owner login, BASIC entitlement, δημιουργία/αλλαγή ρόλου, εργαζόμενο δύο καταστημάτων, ωρομίσθιο, audit και migration preview χωρίς εγγραφή.

## Εκτός αυτού του checkpoint

- εφαρμογή μεταφοράς παλιών εργαζομένων,
- κανόνες εργαζομένων,
- πρότυπα βαρδιών,
- νέος εβδομαδιαίος / μηνιαίος editor,
- άδειες / ρεπό / απουσίες,
- παρουσίες Workforce v2,
- μισθοδοσία και πληρωμές,
- ChatGPT δημιουργία προγράμματος.

Τα παραπάνω συνεχίζονται μόνο σε επόμενα ελεγχόμενα checkpoints.
