# Checkpoint — Προσωπικό & Πρόγραμμα v2

Ημερομηνία: 31/08/2026

## Σκοπός

Έναρξη καθαρής, μη καταστροφικής επανασχεδίασης του module προσωπικού. Το παλιό `Employee / ShiftType / Schedule` παραμένει προσωρινά μόνο ως πιθανή πηγή μεταφοράς δεδομένων και δεν αποτελεί τη βάση της νέας λειτουργίας.

## Υλοποιήθηκε στο checkpoint

- Νέα εμπορικά πακέτα ανά κατάστημα:
  - `PERSONNEL_BASIC`
  - `PERSONNEL_PRO`
  - `PERSONNEL_AI`
  - `PERSONNEL_PAYROLL`
- Ιεραρχία πρόσβασης: AI ⇒ PRO ⇒ BASIC, ενώ PAYROLL ενεργοποιείται ανεξάρτητα.
- Συμβατότητα με την παλιά εγγραφή `AI_STAFF_SCHEDULER` χωρίς απώλεια υπάρχουσας ενεργοποίησης.
- Ο Super Admin διατηρεί μόνιμη πλήρη πρόσβαση.
- Νέο, ανεξάρτητο Prisma schema `Workforce*` για:
  - εργαζόμενους, ρόλους και πρόσβαση σε πολλά καταστήματα,
  - κανόνες, ωρομίσθια και πρότυπα βαρδιών,
  - εβδομαδιαία/μηνιαία προγράμματα και αναθέσεις,
  - άδειες, απουσίες, χτυπήματα και συνεδρίες παρουσίας,
  - περιόδους/γραμμές/κλείσιμο μισθοδοσίας,
  - πληρωμές υπαλλήλων,
  - audit και εντολές ChatGPT με κατάσταση έγκρισης.
- Επέκταση του Platform API ώστε το κάθε πακέτο να ενεργοποιείται, να απενεργοποιείται και να τιμολογείται ξεχωριστά ανά κατάστημα.
- Νέα κεντρική οθόνη Super Admin «Προσωπικό & Πρόγραμμα», με κατάσταση πακέτων, τιμές και σαφή απεικόνιση της νέας βάσης.
- Διατήρηση της σημερινής δημιουργίας προγράμματος μέσα στη νέα οθόνη μέχρι να αντικατασταθεί από τον νέο editor.
- Επιβεβαίωση πριν από κάθε αλλαγή ενεργοποίησης ή τιμής πακέτου.

## Ασφάλεια / συμβατότητα

- Καμία διαγραφή ή μετονομασία παλιού πίνακα.
- Καμία αυτόματη μεταφορά υπαλλήλων στο v2 σε αυτό το checkpoint.
- Καμία αλλαγή στο production `main` χωρίς PR/merge.
- Οι υπάρχουσες κλήσεις που περιμένουν `AI_STAFF_SCHEDULER` συνεχίζουν να λειτουργούν.

## Έλεγχοι

- 5/5 νέες δοκιμές πακέτων και σχήματος επιτυχείς.
- `node --check` επιτυχές για τα νέα/τροποποιημένα server modules.

## Επόμενο checkpoint

1. API εργαζομένων v2 και ελεγχόμενη προεπισκόπηση μεταφοράς παλιών εργαζομένων.
2. Ρόλοι, πρόσβαση σε πολλά καταστήματα και κανόνες εργαζομένων.
3. Νέος εβδομαδιαίος editor με προεπισκόπηση και validation πριν από αποθήκευση.
